# Внешняя проверка: точка входа

## Текущий статус

Этап `v0.3.18` подготовил зафиксированный пакет и синтетически отрепетировал процедуру. Реальное внешнее испытание не проводилось. Следующий допустимый этап `v0.3.19` ограничен независимым рассмотрением пакета и согласованием плана испытания.

## Содержимое каталога

Каталог `contracts/` содержит машиночитаемые схемы ролей, предварительных фиксаций, манифестов и результатов. Эти контракты описывают обмен материалами, но не запускают испытание автоматически.

Зафиксированная человекочитаемая часть пакета находится в `docs/external_review/` и защищена манифестом `v0.3.18`. Для обычного чтения подготовлено [актуальное русское изложение](../docs/guides/external-review/README.md). Исходные файлы нельзя редактировать: они используются для проверки контрольных сумм.

## Роли и организационная граница

Поставщик данных, хранитель эталонной разметки, оценщик, оператор испытания и утверждающий результат имеют разделённые обязанности. На первом контакте передаются навигация по пакету, подтверждённая область применимости, ограничения и перечень артефактов — без реальных данных, меток, секретов и доступа к инфраструктуре.

Колледж не назначен испытательной площадкой. Выбор площадки, передача данных и фактическое испытание требуют отдельного решения. Контрольные списки не являются юридическим заключением.
