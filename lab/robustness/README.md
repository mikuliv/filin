# Лаборатория устойчивости

## Назначение

Подготовка независимых внешних запусков для проверки устойчивости зафиксированной базовой линии датчика.

## Что реализовано

v0.3.2 использует 12 завершено runs: по три topology, background, temporal и combined. Эти данные применяются только к predict/оценка.

## Основные файлы

`run_v0_3_2_stage.py` координирует integrity audits и оценка pipeline.

## Входные данные и выходные данные

Вход — существующая кампания и зафиксированный манифест модели. Выход — отчёты среды выполнения v0.3.2.

## Запуск

`python lab/robustness/run_v0_3_2_stage.py --help`

## Проверки

Модуль запуска с `--resume` должен распознавать успешные запуски и не выполнять кампанию Docker повторно.

## Ограничения

Положительный результат политики не означает готовность к промышленной эксплуатации.
