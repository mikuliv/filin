# Этап обучения v0.3.4

`run_v0_3_4_stage.py` сначала проводит шесть предварительных проверок. Полный запуск
требует путей к политике, отчёту и артефакту; до этого выполняется только безопасная
проверка конфигурации. Обучение состоит из 12 запусков, внутренняя проверка — ещё из
6 отдельных запусков. Политика доступа к данным v0.3.3 запрещает этот этап.

Отбор использует `StratifiedGroupKFold` только по `run_id`. Кандидат фиксируется
до загрузки проверочной выборки; проверка выполняет исключительно предсказание.
