# Непрерывный фоновый трафик

Подсистема v0.3.3 описывает безопасную фоновую активность внутри изолированной сети Docker. Она допускает только разрешённые локальные цели, не более четырёх клиентов, трёх действий в секунду и сорока действий за интервал выполнения. Метаданные аудита не входят в признаки модели.
