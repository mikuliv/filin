# Сценарии атак

Первые сценарии для стенда:

- контролируемое сканирование портов только по Перечень разрешённых значений внутренних сервисов;
- контролируемые ошибки авторизации на тестовой учетной записи;
- безопасный web-probe без реальных вредоносных ов полезной нагрузки;
- низкоинтенсивная имитация всплеска трафика внутри лабораторной сети;
- симуляция маячкового обмена через периодические обращения к внутреннему control-api.

Все сценарии должны иметь лимиты длительности и интенсивности. Внешние цели запрещены.
