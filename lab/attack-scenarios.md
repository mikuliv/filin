# Сценарии атак

Первые сценарии для стенда:

- контролируемое сканирование портов только по перечню разрешённых внутренних сервисов;
- контролируемые ошибки авторизации на тестовой учетной записи;
- безопасная веб-проверка без реальной вредоносной полезной нагрузки;
- низкоинтенсивная имитация всплеска трафика внутри лабораторной сети;
- имитация маячкового обмена через периодические обращения к внутреннему управляющему API.

Все сценарии должны иметь лимиты длительности и интенсивности. Внешние цели запрещены.
