# Контролируемая локальная репетиция

## Назначение

Воспроизводимая локальная проверка транспорта, временных характеристик,
восстановления и подтверждающих материалов сбора.

## Статус

`current laboratory tool`; не внешнее испытание.

## Место в архитектуре

Проверяет staging path основной линии в изолированной среде.

## Основные каталоги

Contracts, модуль запуска components и local fixtures находятся в `rehearsal/`.

## Разрешённые входы и выходы

Зафиксированные синтетические сценарии; результаты пишутся в среду выполнения и
отчёты этапа согласно протоколу.

## Границы и запреты

Запрещены реальные уведомления, внешние конечные точки и трактовка результата как
готовности к промышленной эксплуатации.

## Безопасный запуск

Публикуется только команда конкретного зафиксированного протокола; общий модуль быстрого запуска намеренно отсутствует.

## Тестирование

```powershell
python -m pytest ml/tests/test_v0317_rehearsal.py -q
```

## Источники истины

`rehearsal/contracts/`, протоколы `v0.3.17*` и их решения политики.
