# История научных и исполнительных пакетов

История оформляется как последовательность новых версий, а не как переписывание старых результатов.

| Версия | Назначение | Итог |
|---|---|---|
| v0.3.1–v0.3.3 | базовая оценка и контролируемые сдвиги | выявлена потеря benign-класса |
| v0.3.4–v0.3.11 | переработка представления, uncertainty и episode policy | создан frozen candidate |
| v0.3.12–v0.3.13 | regression и независимый environmental holdout | holdout локальный, внешняя применимость не доказана |
| v0.3.14 | аудит компонентов и контракта | scope full fault readiness пересмотрен |
| v0.3.15–v0.3.15.3 | passive trial, corrective audit и анализ регрессии | старые runtime claims не подтверждены исходным путём |
| v0.3.15.4–v0.3.15.5.1 | новая разработка, holdout и восстановление контракта | scientific holdout положителен по подполитикам, runtime восстановлен отдельно |
| v0.3.16 | локальный изолированный staging transport | 2 280/2 280 событий, 59/59 gates |
| v0.3.17 | длительная локальная репетиция | 201 420 согласованных событий, общий policy отрицателен |

Для v0.3.17 документ [протокола](experiments/v0_3_17.md) объясняет недействительные revision 1–5 и авторитетную revision 6. Их данные сохранены, но не используются как доказательство. Scientific protocol, кандидат и контрольные суммы не изменялись при исправлении документации.
