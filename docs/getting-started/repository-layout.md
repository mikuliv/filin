# Структура репозитория

Каталоги в таблице разделены по назначению и уровню доверия. Перед изменением
файла проверьте его статус: сопровождающая документация может ссылаться на
защищённый источник, но не должна переписывать его.

| Каталог | Назначение | Хранение | Статус | Основная проверка | Что запрещено |
|---|---|---|---|---|---|
| `backend/` | ранний прототип API | отслеживается | исторический | исторические тесты | считать его текущей серверной частью |
| `collectors/` | сбор и нормализация Zeek/Suricata/CSV, пассивная среда выполнения | отслеживается | текущий | тесты сборщиков | промышленный захват без отдельного этапа |
| `datasets/` | правила и описания наборов | отслеживаемые метаданные | текущая справочная область | проверки происхождения | фиксировать чувствительные исходные данные в Git |
| `docs/` | текущая документация, статус и история | отслеживается | текущий | проверка документации v2 | менять зафиксированные подтверждающие материалы |
| `examples/` | безопасные примеры | отслеживается Git | справочный | тесты примеров | реальные идентификаторы и секреты |
| `external_review/` | исполняемые контракты внешней процедуры | отслеживается/зафиксировано | ограниченный | проверка пакета | запускать испытание автоматически |
| `incident_reconstruction/` | факты, отношения, разрывы, гипотезы и карточки | отслеживается | текущий лабораторный | проверки v0.4 | трактовать граф как доказательство причинности |
| `lab/` | локальные стенды и сценарии | отслеживается Git | исследовательский | лабораторные тесты | выход из изоляции |
| `lab/network_validation/` | Phase 1: план, генераторы, захват, Zeek и контракты среды выполнения | отслеживается + внешние секреты отдельно | технический, научный запуск не выполнен | статические контрактные проверки | запускать единицу без нового пакета и явного допуска |
| `lab_console/` | локальный интерфейс и изменяемый слой оператора | отслеживается + среда выполнения | текущий лабораторный | проверки консоли | публичная привязка и автоматические действия |
| `ml/` | признаки, артефакты, протоколы и отчёты | отслеживается/зафиксировано | текущий и исторический | pytest и проверки пакетов | переписывать зафиксированные отчёты |
| `rehearsal/` | локальная контролируемая репетиция | Git и среда выполнения | текущий лабораторный | тесты репетиции | считать внешним испытанием |
| `runtime/` | базы, журналы и временные отчёты | только в среде выполнения | изменяемый | очистка и проверки | считать подтверждающими материалами по умолчанию |
| `staging/` | эталонный приёмник и транспорт | отслеживается + среда выполнения | текущий лабораторный | тесты staging | называть промышленной серверной частью |
| `tools/` | генераторы, проверки и верификаторы | отслеживается | текущий | профильные тесты | обходить зафиксированную политику |

README каждого компонента определяет входы, выходы и безопасные команды. Полный
каталог: [component-directory](../reference/component-directory.md).

Лицензионные материалы размещены в `LICENSES/`, `docs/licensing/`, `licensing/`,
`distribution/profiles/` и `sbom/`. Генераторы и проверки находятся в
`tools/licensing/`; зафиксированные файлы получают назначение через `REUSE.toml`
без изменения байтов.
