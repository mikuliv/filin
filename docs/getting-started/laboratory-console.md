# Запуск лабораторной консоли

## Назначение и границы

Лабораторная консоль — локальный интерфейс для просмотра синтетических карточек, лабораторных запусков, предложений кандидатов и результатов слепой проверки. Она не является SIEM, промышленным сервером или средством автоматического реагирования. Консоль не выбирает модель, не меняет действующего кандидата и не изменяет зафиксированные материалы.

## Предварительные условия

- команды выполняются из корня репозитория;
- установлен Python и зависимости проекта;
- адрес ограничен `127.0.0.1`;
- задан непубликуемый одноразовый токен;
- каталог `runtime/lab_console/` доступен для записи.

## Запуск

```powershell
$env:FILIN_CONSOLE_TOKEN = "локальный-одноразовый-токен"
python -m lab_console --host 127.0.0.1 --port 8043
```

Откройте `http://127.0.0.1:8043/ui/cases`, введите токен и завершите вход. Успешный результат — открытый каталог лабораторных карточек и отметка локального режима в шапке.

## Что сохраняется

Изменяемый слой SQLite в `runtime/lab_console/` хранит ход рассмотрения, состояния пунктов, заметки и решения. Исходные пакеты читаются без изменения. Токен, cookie и содержимое базы не включаются в Git и экспорт доказательств.

## Порядок работы

1. Выберите карточку или лабораторный запуск.
2. Проверьте происхождение исходных данных и ограничения.
3. Последовательно изучите факты, временную шкалу, граф, разрывы и гипотезы.
4. Используйте матрицу только как попарное сравнение поддержки, а не как рейтинг.
5. Ответьте на вопросы специалисту только при наличии первичного материала.
6. Зафиксируйте нерешённые вопросы, ограничения и следующий ручной шаг.
7. Экспортируйте завершённое рассмотрение.

## Ошибки и восстановление

- `FILIN_CONSOLE_TOKEN` не задан: задайте токен в том же процессе оболочки и повторите запуск;
- адрес уже занят: завершите прежний локальный процесс либо выберите свободный порт;
- состояние не найдено: проверьте путь к `runtime/lab_console/` и права записи;
- проверка источника не пройдена: не исправляйте зафиксированный пакет, остановите рассмотрение и запишите ограничение.

После штатного перезапуска сохранённый изменяемый слой восстанавливается автоматически. Удаление базы означает создание новой локальной сессии, но не меняет исходные материалы.


## Полномочия и запреты

Разрешены только встроенные процедуры из перечня разрешённых значений. Запрещены внешний адрес, сеть, произвольные команды, загрузка исполняемых файлов, обучение на слепых данных, автоматическое продвижение и промышленное решение. Авторитетными остаются версионированные контракты и зафиксированные манифесты, а не текст интерфейса или заметка оператора.

Подробный рабочий цикл описан в [руководстве по карточкам](reviewing-laboratory-cards.md), команды — в [справочнике](../reference/command-reference.md).
