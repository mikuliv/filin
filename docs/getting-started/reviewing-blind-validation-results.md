# Рассмотрение результатов слепой проверки

## Назначение

Ручное рассмотрение отделяет техническую корректность слепой процедуры от научного решения по обязательным критериям.

## Предварительные условия

- оба пакета прогнозов зафиксированы до раскрытия разметки;
- оценка воспроизводится детерминированно;
- сопоставимость подтверждена;
- доступны результаты 24 обязательных критериев.

## Порядок работы

1. Проверьте отчёты об отсутствии пересечений и сохранении слепого режима.
2. Сопоставьте предварительную фиксацию пакетов прогнозов с фактическими файлами.
3. Изучите показатели по классам, эпизодам и отказам от решения.
4. Рассмотрите различия карточек, разрывов и гипотез.
5. Проверьте каждый обязательный критерий без скрытых весов.
6. Запишите ограничения и необъяснённые различия.
7. Сохраните решение и подготовьте локальный экспорт.

## Ожидаемый результат

Для v0.4.7 сохраняется решение `failed_validation`: пройдено 18 из 24 критериев, шесть критических различий не устранены. Требуется независимая человеческая проверка.

## Возможные ошибки

Нельзя завершить рассмотрение при пропущенном шаге, изменённом пакете прогнозов, неверной версии или недоступном критерии.

## Ограничения и запреты

Техническое разделение ролей не равно независимому рассмотрению разными людьми. Запрещены регистрация предложения, изменение действующего кандидата, промышленная эксплуатация и разрешение v0.4.8. Авторитетный итог: `ml/reports/v0_4_7/v0_4_7_policy_result.json`.

```powershell
python -m tools.lab_console.verify_v047
```
