# Рассмотрение результатов слепой проверки

Сначала проверяйте integrity gates, затем comparability и только потом метрики. `failed_validation` означает провал обязательных порогов предложения; корректно выполненная процедура при этом остаётся подтверждённой.

В v0.4.7 независимого человека нет, поэтому решение не может быть `passed_for_registration_review`. Допустимый следующий шаг — отдельная независимая человеческая проверка; v0.4.8 не разрешён.
