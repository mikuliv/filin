# Как рассмотреть отрицательный результат

1. Откройте в консоли раздел «Разбор отрицательного результата».
2. Сверьте шесть исходных идентификаторов критериев с зафиксированным результатом v0.4.7.
3. Изучите матрицы ошибок, классы, сессии, уверенность и доступность признаков.
4. Для каждой причины сопоставьте подтверждающие и противоречащие материалы.
5. Проверьте корректирующие действия и запрет повторного использования раскрытого набора.
6. Завершите просмотр проверкой готовности нового предложения.

Интерфейс доступен только для чтения. Он не содержит действий изменения старого решения, повторного обучения, регистрации, активации или продвижения.
