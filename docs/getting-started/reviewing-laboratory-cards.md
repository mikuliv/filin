# Рассмотрение лабораторных карточек

Откройте `/ui/cases`. Каталог содержит 12 независимых синтетических случаев. Фильтры класса, сложности, наличия разрывов и состояния review работают локально; порядок карточек не является оценкой опасности.

## Операторский цикл

1. На обзоре прочитайте наблюдаемое описание и safety-ограничения, затем создайте review.
2. В разделе «Факты» откройте источник хотя бы одного ключевого факта. Факт остаётся отделённым от модельной интерпретации.
3. На временной шкале сравните время наблюдения и доставки. Порядок не доказывает причинность.
4. В графе выберите узел и ребро, прочитайте ограничения и постройте путь к гипотезе.
5. Для разрыва откройте влияние. Отметка оператора не устраняет разрыв без нового материала.
6. Просмотрите все гипотезы, одну недиагональную ячейку матрицы и вопросы специалисту.
7. В review отметьте 13 обязательных пунктов, добавьте безопасную текстовую заметку и завершите рассмотрение без окончательного определения.
8. Сформируйте экспорт и проверьте source bundle SHA и source semantic SHA.

Состояние сохраняется в локальном SQLite-overlay и восстанавливается после перезапуска. Заметки не являются evidence, не меняют исходный bundle или semantic SHA и не принимают HTML/script. Завершённая сессия неизменяема.

## Проверка

```powershell
python tools/lab_console/build_v044_cases.py
python tools/lab_console/run_v044_campaign.py
python tools/lab_console/verify_v044.py
python -m pytest ml/tests/test_v044_operator_cycle.py
```

Консоль работает только на localhost. Она не подключает backend, не принимает реальные PCAP и не выполняет автоматические действия.
