# Устранение неполадок

## Консоль не открывается

Проверьте, что порт 8043 свободен, процесс запущен из корня репозитория и адрес равен
`127.0.0.1`. Не заменяйте его на публичный bind.

## Вход отклонён

Создайте новый локальный `FILIN_CONSOLE_TOKEN` и повторите вход. Не записывайте токен
в файл отслеживаемый или журнал issue.

## Интерфейс показывает старую версию

Перезапустите процесс консоли и выполните полную перезагрузку страницы в браузере. Статические ресурсы
имеют версию для сброса кеша; ручное редактирование зафиксированных отчётов не требуется.

## Тесты оставили файлы среды выполнения

Проверьте `git status`. Удаляйте только воспроизводимые неотслеживаемые файлы внутри
`runtime/`, убедившись, что путь относится к текущему репозиторию. Не удаляйте отслеживаемые подтверждающие материалы.

## Проверка документации сообщает ошибку

Исправьте первопричину, затем перестройте опись:

```powershell
python -m tools.docs.build_documentation_inventory
python -m tools.docs.validate_documentation_v2 --strict
```

Не отключайте правило и не перегенерируйте зафиксированный артефакт, чтобы скрыть найденную проблему.
