# Запуск слепой лабораторной проверки

1. Зафиксируйте protocol, control pack и label commitment ролью хранителя.
2. Проверьте overlap и blindness.
3. Заморозьте prediction plan и выполните active/proposal inference.
4. Зафиксируйте оба prediction package.
5. Авторизуйте и выполните label unlock ролью evaluator.
6. Рассчитайте метрики, comparability и frozen acceptance gate.
7. Завершите 29-пунктовое ручное рассмотрение.

Воспроизводимый локальный сценарий: `python tools/lab_console/v047_stage.py`. Он не использует сеть и не меняет кандидатов.
