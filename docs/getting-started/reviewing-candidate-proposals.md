# Рассмотрение предложения кандидата

## Назначение

Рассмотрение фиксирует проверку происхождения, воспроизводимости, совместимости и научных ограничений предложения без регистрации кандидата.

## Предварительные условия

- обучение завершено и воспроизведено;
- предложение зафиксировано;
- предварительная внутренняя проверка завершена;
- обязательные критерии допуска рассчитаны до ручного решения.

## Порядок работы

1. Откройте карточку предложения.
2. Сопоставьте артефакт, семантический отпечаток и манифест.
3. Проверьте происхождение данных, разбиение и отсутствие утечки.
4. Изучите показатели предложения и действующего кандидата без выбора победителя.
5. Проверьте каждый обязательный критерий допуска.
6. Заполните контрольный список и заметку эксперта.
7. Выберите только разрешённое решение и сохраните ограничения.
8. Подготовьте экспорт рассмотрения.

## Ожидаемый результат

Сохраняется версионированное решение. Даже допуск к отдельной проверке (`admitted_to_separate_validation`) не регистрирует кандидата.

## Возможные ошибки

Решение отклоняется при незавершённых шагах, проваленном обязательном критерии, неверной версии рассмотрения или изменённом предложении.

## Ограничения и запреты

Нельзя считать внутреннюю проверку внешним подтверждением, скрывать отрицательный критерий, менять действующий кандидат или разрешать промышленную эксплуатацию.

```powershell
python -m tools.lab_console.verify_v046
```
