# Ручное рассмотрение предложения

Оператор последовательно проверяет lineage, split/leakage, обучения, fingerprint, screening, совместимость, метрики, class/FPR/abstention результаты, reconstruction diffs, admission gate, ограничения и лицензионный статус. Progress и версии review сохраняются после перезапуска.

Допустимы `admitted_to_separate_validation` и `rejected`. Первый статус разрешает только подготовку отдельного протокола; второй закрывает или возвращает предложение на исследование. Ни один статус не регистрирует и не активирует модель.

Экспорт не содержит model binary, dataset, секреты или абсолютные пути.
