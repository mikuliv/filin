# Точка входа аудитора

Аудитору нужно разделять три вещи: читаемое объяснение, машиночитаемый контракт
и зафиксированный результат. Сначала устанавливается версия и целостность, и
только затем оценивается содержание.

## Порядок проверки

1. Сопоставьте [читаемый статус](../status/current-status.md) с обоими реестрами YAML.
2. Проверьте реестр кандидатов и манифест кандидата.
3. Найдите этап в [индексе протоколов](../protocols/index.md).
4. Откройте результат политики, манифест, detached SHA и журнал связи утверждений
   с подтверждениями через [индекс отчётов](../reports/index.md).
5. Прочитайте limitations и negative results.
6. Выполните reproduction command только в разрешённой локальной области.
7. Проверьте [protected set](../audit/protected_documentation_v2.json).

Краткое описание документа не имеет приоритета над зафиксированной политикой.
Несовпадение манифеста baseline,
если он существовал до текущего прохода, фиксируется отдельно и не скрывается.
