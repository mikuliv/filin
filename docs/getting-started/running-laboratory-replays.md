# Выполнение лабораторного replay

Повтор воспроизводит уже описанный лабораторный запуск с теми же входами и
параметрами. Он не является новым научным циклом и не должен незаметно менять
кандидата, пороги или зафиксированный протокол.

Откройте «Лабораторные запуски», выберите разрешённые шаблон, кандидата и вход. Проверьте пробный запуск без выполнения и явно подтвердите исполнение. Путь, команда, argv, пороги и произвольный seed не вводятся.

После прерывания автоматический повтор запрещён. Оператор выбирает продолжение из контрольной точки или фиксацию ошибки. Для завершённого запуска проверьте контрольную сумму плана, среду, показатели, указатель артефактов и манифест.
