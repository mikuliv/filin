# Выполнение лабораторного replay

Откройте «Лабораторные запуски», выберите разрешённые шаблон, кандидата и вход. Проверьте пробный запуск без выполнения и явно подтвердите исполнение. Путь, команда, argv, пороги и произвольный seed не вводятся.

После прерывания автоматический повтор запрещён. Оператор выбирает продолжение из checkpoint или фиксацию failure. Для завершённого запуска проверьте Контрольная сумма плана, environment, показатели, артефакт index и манифест.
