# Выполнение лабораторного replay

Откройте «Лабораторные запуски», выберите разрешённые шаблон, кандидата и вход. Проверьте dry run и явно подтвердите исполнение. Путь, команда, argv, пороги и произвольный seed не вводятся.

После прерывания автоматический повтор запрещён. Оператор выбирает продолжение из checkpoint или фиксацию failure. Для завершённого запуска проверьте plan SHA, environment, metrics, artifact index и manifest.
