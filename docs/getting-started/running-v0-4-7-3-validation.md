# Проверка материалов v0.4.7.3

Этап уже выполнен; эта инструкция проверяет сохранённые материалы и не запускает новый научный цикл.

```powershell
python -m tools.lab_console.verify_v0473
python -m pytest ml/tests/test_v0473_blind_validation.py -q
```

Полный проход данных и бинарные пакеты находятся только в каталоге среды выполнения. Для воспроизведения процедуры требуются исходная ревизия Git, замороженный протокол и уже существующие локальные артефакты моделей. Сеть, произвольные команды, загрузка модели и изменение кандидата не используются.

Результат `failed_validation` является ожидаемым сохранённым итогом. Успешное средство проверки подтверждает целостность процедуры, а не положительное качество модели.
