# Сравнение лабораторных запусков

Выберите два завершённых запуска. Сначала прочитайте результат comparability gate. При `not_comparable` не интерпретируйте дельту качества: разрешён только provenance side-by-side.

Затем проверьте метрики, классы, эпизоды, карточки, gaps, hypotheses и explanation records. Завершайте review статусом `closed_without_candidate_decision`. Review не меняет исходные результаты и кандидата.
