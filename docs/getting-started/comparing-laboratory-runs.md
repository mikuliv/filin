# Сопоставление лабораторных запусков

## Назначение

Руководство помогает определить, допустимо ли сравнивать два воспроизводимых запуска, и объяснить найденные различия без автоматического выбора победителя.

## Предварительные условия

- оба запуска завершены и зарегистрированы в локальном каталоге;
- планы, входные манифесты и контрольные суммы доступны;
- исходные материалы не изменялись после выполнения;
- лабораторная консоль запущена локально.

## Порядок работы

1. Откройте раздел «Сравнения запусков».
2. Выберите левый и правый запуск.
3. Выполните проверку сопоставимости.
4. Если запуски несопоставимы (`not_comparable`), изучите причины и не интерпретируйте разницу показателей как качество модели.
5. Если сравнение допустимо, последовательно изучите происхождение, окружение, выполнение, показатели, классы, эпизоды, карточки, разрывы и гипотезы.
6. Создайте сеанс ручного рассмотрения, запишите объяснённые и необъяснённые различия.
7. Подготовьте локальный экспорт; исходные запуски при этом не изменяются.

## Ожидаемый результат

Сохраняются оценка сопоставимости, комплект различий, заметки оператора и решение рассмотрения. Решение не регистрирует кандидата.

## Возможные ошибки

- отсутствует завершённый запуск;
- контрольная сумма входов не совпадает;
- различаются обязательные контракты;
- недоступен локальный файл результата;
- сравнение уже закрыто и доступно только для чтения.

## Ограничения и запреты

Запрещены произвольные команды, сеть, изменение исходных запусков, скрытое взвешивание критериев и автоматическое продвижение модели. Авторитетными источниками служат записи каталога запусков и их манифесты.
