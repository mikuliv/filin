# Жизненный цикл документов

| Жизненный цикл | Значение | Разрешённое изменение |
|---|---|---|
| `current` | текущий канонический документ | обычный проверенный коммит |
| `historical` | описание завершённого состояния | только явный перечень исправлений или навигация |
| `redirect` | совместимый старый путь | только смена канонической цели |
| `generated` | представление реестра или дерева | только через генератор |
| Зафиксировано | байты входят в множество защищённых файлов | изменение запрещено |

Метаданные всех отслеживаемых файлов Markdown хранятся в каноническом
[`documentation_inventory_v2.json`](../audit/documentation_inventory_v2.json).
Человекочитаемые страницы начинаются с H1 и не показывают служебный YAML Служебный заголовок.
Зафиксированные файлы не получают метаданные внутри собственных неизменяемых байтов.

Перед перемещением проверяются входящие ссылки и манифесты. Старый путь сохраняется
перенаправление, если он публичен, исторически упомянут или на него ссылается контракт.
