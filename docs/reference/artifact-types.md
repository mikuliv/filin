# Типы артефактов

- **протокол** — заранее зафиксированный набор правил, определяющий область применения, входные данные, контрольные условия и запреты;
- **результат политики** — машиночитаемый итог проверки контрольных условий;
- **манифест комплекта** — список путей, размеров, ролей и контрольных сумм SHA;
- **отделённая контрольная сумма SHA** — отдельная фиксация идентичности манифеста;
- **реестр утверждений и подтверждающих материалов** — связь утверждений с поддерживающими артефактами;
- **журнал запуска** — команды, отметки времени и сведения о среде;
- **сводка** — человекочитаемый итог без собственной расширяющей силы;
- **контракт или схема** — версионированные форма и ограничения данных;
- **семантическая контрольная сумма** — идентификатор нормализованного значимого содержимого;
- **изменяемый слой среды выполнения** — изменяемое состояние, которое по умолчанию не является зафиксированным подтверждающим материалом.
