# Глоссарий проекта «Филин»

Русское название используется как основное. Точный программный идентификатор приводится в обратных кавычках только там, где он нужен для проверки файла, команды или ответа программного интерфейса.

## Кандидаты и модели

- **действующий кандидат** (`active_candidate`) — неизменяемая связка модели, предварительной обработки, калибровки и правил принятия решения; текущий идентификатор — `v03154:65a3dd912d845bc1`;
- **предложение кандидата** (`proposal`) — отдельный лабораторный результат обучения, который ещё не зарегистрирован как кандидат;
- **реестр кандидатов** (`candidate_registry`) — авторитетный машиночитаемый перечень зарегистрированных версий;
- **применение модели** (`inference`) — формирование прогнозов для заранее заданного набора входных данных;
- **пакет прогнозов** (`prediction_package`) — зафиксированный набор прогнозов одного участника проверки;
- **отказ от решения** (`abstention`) — сохранение неопределённости вместо принудительного выбора класса.

## Данные и разметка

- **набор данных** (`dataset`) — организованная совокупность наблюдений;
- **разбиение данных** (`split`) — зафиксированное распределение наблюдений между назначенными частями;
- **отложенная контрольная выборка** (`holdout`) — данные, не использованные для подбора кандидата;
- **контрольный набор** (`control_pack`) — изолированный набор для слепой проверки;
- **пакет эталонной разметки** (`label_package`) — неизменяемые правильные ответы;
- **раскрытие разметки** (`label_unlock`) — разрешённое предоставление эталонных меток только после фиксации прогнозов;
- **тестовый эталон** (`test_oracle`) — ожидаемый результат, доступный только проверочному коду.

## Целостность

- **артефакт** (`artifact`) — файл или комплект файлов, полученный на определённом этапе;
- **исходный артефакт** (`source_artifact`) — материал, на котором основан последующий результат;
- **манифест** (`manifest`) — реестр состава с контрольными суммами;
- **предварительная криптографическая фиксация** (`commitment`) — контрольная сумма, опубликованная до раскрытия закрытых сведений;
- **семантическая контрольная сумма** (`semantic_sha256`) — контрольная сумма нормализованного значимого содержания;
- **семантический отпечаток** (`semantic_fingerprint`) — воспроизводимое представление значимой структуры объекта;
- **история происхождения** (`lineage`) — связь результата с исходными материалами и преобразованиями;
- **происхождение** (`provenance`) — проверяемые сведения об источнике файла или результата.

## Проверка и рассмотрение

- **слепая проверка** (`blind_validation`) — процедура, при которой эталонная разметка недоступна во время формирования прогнозов;
- **проверка с разделением ролей** (`role_separated_blind`) — техническое разделение хранения данных, применения модели, оценки и рассмотрения;
- **независимая человеческая проверка** — рассмотрение отдельным человеком, не выполнявшим другие роли;
- **проверка отсутствия пересечений** — подтверждение независимости контрольного набора от прежних данных;
- **проверка сохранения слепого режима** — подтверждение отсутствия доступа к разметке до фиксации прогнозов;
- **проверка сопоставимости** — определение допустимости сравнения двух запусков;
- **обязательные критерии допуска** — зафиксированный набор условий, без которых предложение нельзя передавать на следующий этап;
- **обязательные критерии приёмки** — зафиксированные научные и технические пороги результата;
- **решение «проверка не пройдена»** (`failed_validation`) — не выполнен хотя бы один обязательный критерий; это не означает техническую ошибку процедуры.

## Реконструкция

- **наблюдаемый факт** — утверждение, непосредственно связанное с подтверждающим материалом;
- **временная последовательность** — порядок наблюдений без утверждения о причинности;
- **граф связей** — проверяемые отношения между фактами, разрывами и гипотезами;
- **разрыв реконструкции** — явно представленное отсутствие необходимых сведений;
- **гипотеза** — конкурирующее объяснение, которое не считается установленным фактом;
- **равная поддержка** (`equally_supported`) — имеющиеся сведения не дают одной гипотезе преимущества.

## Эксплуатация

- **среда выполнения** (`runtime`) — локальная изменяемая область для баз данных, временных файлов и снимков;
- **только для чтения** (`read_only`) — режим, запрещающий изменение исходного материала;
- **изменяемый слой** (`overlay`) — отдельная область заметок и решений оператора;
- **серверная часть** (`backend`) — программные компоненты обработки и хранения данных;
- **промышленная эксплуатация** (`production`) — работа с реальными системами и операционными последствиями;
- **пассивное наблюдение** (`shadow_mode`) — получение результатов без автоматического воздействия;
- **пробный запуск без выполнения** (`dry_run`) — проверка плана без запуска разрешённой процедуры;
- **порядок работы** (`workflow`) — последовательность действий оператора или программы;
- **модуль запуска** (`runner`) — ограниченный исполнитель заранее разрешённых процедур.

## Форматы и программы

- **программный интерфейс приложения (API)** — стабильные адреса и структуры запросов;
- **файл записи сетевых пакетов (PCAP)** — формат сохранённого сетевого обмена;
- **криптографическая контрольная сумма SHA-256** — идентификатор байтового содержимого;
- **система управления версиями Git** — средство хранения истории проекта;
- **анализатор сетевого трафика Zeek** и **система сетевого анализа Suricata** — внешние программы, чьи собственные названия не переводятся.
