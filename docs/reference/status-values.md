# Значения статусов

| Значение | Толкование |
|---|---|
| `completed` | этап завершён, итог определяется отдельным результатом политики |
| `passed` | Зафиксированные критерии этапа пройдены в пределах его области применимости |
| `negative` / `failed` | одно или несколько обязательных контрольных условий не пройдены |
| `completed_reassessed` | исторический этап сохранён, поздний аудит ограничил утверждения |
| `current` | документ или компонент применим к текущей архитектуре |
| `historical` | сохранён для истории, не относится к текущему пути выполнения |
| `laboratory_only` | подтверждено только в контролируемой лабораторной области |
| `not_reviewed` | оператор ещё не зафиксировал рассмотрение элемента |
| `unresolved` | вопрос остаётся открытым |

`completed` не равно `passed`, а `passed` не означает готовность к промышленной эксплуатации.
