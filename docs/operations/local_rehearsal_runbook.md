# Порядок локальной репетиции v0.3.17

## Предусловия

1. Рабочая копия чистая, а состояние HEAD и дерево серверной части соответствуют зафиксированным протоколу и коду.
2. Docker доступен; образы `python:3.11-slim`, `zeek/zeek:7.0.5` и локальный `filin-rehearsal-v0317:local` совпадают с зафиксированными контрольными суммами.
3. `runtime/v0_3_17` отсутствует или пуст; протокол и предварительная фиксация кода кампании прошли проверку.
4. Внешняя сеть, опубликованный порт, конечная точка серверной части и реальные данные не используются.

Запуск выполняется единственной командой `python -m ml.experiments.v0_3_17.run_campaign --start`. Модуль запуска действует по принципу безопасного отказа (fail-closed) и отклоняет изменённый протокол, исходный файл или контрольную сумму образа. Три запуска занимают не менее четырёх фактических часов; ускорение времени не поддерживается.

Во время выполнения проверяются файл комментариев и состояния, здоровье контейнеров, подтверждения захвата, ход работы приёмника, очередь и частота сбора сведений о ресурсах. Исходные данные среды выполнения не добавляются в Git. Плановое обслуживание выполняется только по зафиксированным смещениям. Нештатная ошибка не исправляется на работающей кампании: кампания сохраняется и признаётся недействительной согласно протоколу.

После завершения запускаются финализатор, строгий комплект валидаторов, поведенческие тесты, семантическая проверка документации, проверка исключений и компиляция. Только очищенные `ml/reports/v0_3_17` добавляются принудительно, поскольку общее пространство отчётов игнорируется.
