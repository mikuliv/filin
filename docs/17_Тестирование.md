# Тестирование

Тесты разделены на научные контракты, сенсор, пассивную доставку и прототип backend. Минимальный regression-набор:

```bash
python -m pytest ml/tests
python -m pytest collectors/shadow/tests
python -m pytest collectors/shadow_trial/tests
python -m pytest backend/tests
```

Первый блок проверяет схемы, протоколы, split и политику оценки; второй — канонические события, приватность, ACK, повторы и восстановление; третий сохраняет историческое поведение trial; четвёртый относится к отдельному backend-прототипу. Тесты не должны запускать научную кампанию, создавать секрет или изменять frozen artifacts.

Для документационного прохода дополнительно выполняется `git diff --check`, проверка относительных ссылок и поиск англоязычных описательных слов. Кодовые идентификаторы, имена технологий и команды исключаются из механической проверки вручную.
