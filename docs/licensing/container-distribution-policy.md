# Политика контейнерного распространения

- Suricata — необязательный сторонний компонент под GPL-2.0-only; образ и исходники не входят в основной автономный комплект.
- Elasticsearch, Kibana и Filebeat — необязательные лабораторные зависимости; пользователь получает их самостоятельно, они исключены из дистрибутива.
- Zeek — сторонняя ссылка и не является собственным компонентом.
- Docker Desktop — внешний инструмент разработки, не часть дистрибутива.
- Базовые образы Python и nginx, а также пакеты apt учитываются как внешние зависимости сборки и выполнения; профили исходников содержат только декларации ссылок.

Сборка автономного комплекта сторонних компонентов запрещена до отдельной проверки лицензий, уведомлений, исходников и условий каждого образа.
