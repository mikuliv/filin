# Исторический backend

Исторические варианты backend включены в инвентаризацию происхождения и лицензируются как собственный исходный код по MPL-2.0, если манифест не указывает иное. Они не объявляются текущим runtime и не изменяются этим этапом. Зафиксированное baseline-дерево backend: `04218a4eb01534950efd5f7d6390f1a575cacbc8`.
