# Соответствие REUSE

`REUSE.toml` соответствует формату REUSE Specification 3.3: общая MPL-2.0 annotation и более поздние `override` для документации и официальных license texts. Собственный offline-validator проверяет однозначное покрытие всех файлов отслеживаемый и наличие текстов лицензий. При наличии внешней команды дополнительно допустим `reuse lint`.

Override для официальных текстов указывает upstream holder: Mozilla Foundation and contributors, Creative Commons и The Linux Foundation and contributors. Имя автора проекта этим файлам не назначается.
