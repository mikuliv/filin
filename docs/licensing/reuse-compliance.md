# Соответствие REUSE

`REUSE.toml` соответствует спецификации REUSE 3.3: общее указание MPL-2.0 и более поздние `override` для документации и официальных текстов лицензий. Собственная автономная проверка контролирует однозначное покрытие всех отслеживаемых файлов и наличие текстов лицензий. При наличии внешней команды дополнительно допустим `reuse lint`.

Переопределение для официальных текстов указывает исходных правообладателей: Mozilla Foundation с участниками, Creative Commons и Linux Foundation с участниками. Имя автора проекта этим файлам не назначается.
