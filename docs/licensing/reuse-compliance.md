# REUSE compliance

`REUSE.toml` соответствует формату REUSE Specification 3.3: общая MPL-2.0 annotation и более поздние `override` для документации и официальных license texts. Собственный offline-validator проверяет однозначное покрытие всех tracked-файлов и наличие текстов лицензий. При наличии внешней команды дополнительно допустим `reuse lint`.
