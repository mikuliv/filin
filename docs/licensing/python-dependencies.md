# зависимости Python

Объявления извлекаются из всех отслеживаемых файлов `requirements*.txt`; локально установленные дистрибутивы и их транзитивное замыкание — через `importlib.metadata`. Выражения лицензий, классификаторы и файлы лицензий рассматриваются как подтверждающие материалы; нормализация в SPDX фиксируется отдельно. Сеть и установка пакетов не используются.

Неизвестная или неоднозначная лицензия, необъявленный import, отсутствующий distribution и dependency без диапазона версий являются блокерами строгой проверки. Машинные реестры: `python-dependencies-declared.json` и `python-dependencies-resolved.json`.
