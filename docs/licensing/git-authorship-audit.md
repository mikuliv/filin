# Аудит авторства Git

Проверяется `git log --all`: автор, лицо, выполнившее коммит, `Co-authored-by`, коммиты слияния и импорта, первый и последний коммиты. Два варианта адреса электронной почты `mikuliv` подтверждены как принадлежащие Руслану Покатилову; техническая учётная запись GitHub, выполнившая коммит, не трактуется как автор.

Актуальные числа находятся в `git-authorship.json`. Неизвестная идентичность даёт стабильный код `unknown_author`, `unknown_committer` или `unknown_coauthor` и блокирует готовность к распространению.
