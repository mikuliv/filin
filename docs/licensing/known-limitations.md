# Известные ограничения

- Git-аудит видит только сведения в доступных refs и не доказывает отсутствие внешних договорённостей.
- Локальная Python-инвентаризация зависит от установленного окружения; CI проверяет объявления без сетевой установки.
- Отсутствующие локально контейнеры имеют статус `not_available_offline`; это не означает проверку их содержимого.
- Системные пакеты окончательно проверяются средствами конкретного базового дистрибутива при сборке.
- SPDX SBOM — внутренний совместимый профиль SPDX 2.3, созданный без внешнего генератора.
- Новые файлы этого единственного итогового коммита используют provenance-маркер `FINAL_LICENSING_COMMIT_SELF_REFERENCE`: SHA коммита невозможно вложить в его собственное содержимое без изменения этого SHA.
- Это техническая инвентаризация, не юридическое заключение, гарантия патентной чистоты или разрешение на промышленное применение.
- `release_ready=true` не относится к offline third-party bundle, model package или dataset package; его область ограничена `approved_source_profiles_only`.
