# Аудит происхождения файлов

Для 100% отслеживаемых файлов фиксируются SHA-256, первый коммит, дата и исходная идентичность автора по полной истории ссылок. Переименования учитываются через записи о переименовании. Отсутствие первого появления блокирует строгую проверку кодом `file_provenance_missing`.

Машинный результат: `file-provenance-audit.json`.
