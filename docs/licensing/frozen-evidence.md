# Зафиксировано подтверждающие материалы и лицензирование без изменения байтов

Защищённый набор строится существующим `tools.docs.documentation_v2.build_protected_set`. Этап не добавляет комментарии SPDX в такие файлы и не изменяет их байты. Лицензия назначается внешне через `REUSE.toml` и отражается в `frozen-spdx-mapping.json` с исходным SHA-256 и защищающими манифестами.

Это сохраняет научную воспроизводимость и одновременно делает назначение лицензии машиночитаемым.

Исходный `frozen-spdx-mapping.json` сохраняется как историческая таблица и задним числом не переписывается. Обнаруженные записи со смешанным basis LF/CRLF и последующее расширение защищённого множества оформляются отдельным `frozen-spdx-mapping-correction-v1.json`. Коррекция перечисляет каждый путь явно, связывает прежний digest с SHA канонического Git blob и не разрешает универсальный fallback по окончаниям строк.

`licensing/repository-license-manifest.json` имеет другой жизненный цикл: это текущая изменяемая лицензионная опись репозитория. Она перестраивается для текущего Git-состояния и не служит scientific freeze.
