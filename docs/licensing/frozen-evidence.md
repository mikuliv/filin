# Зафиксированные подтверждающие материалы и лицензирование без изменения байтов

Защищённый набор строится существующим `tools.docs.documentation_v2.build_protected_set`. Этап не добавляет комментарии SPDX в такие файлы и не изменяет их байты. Лицензия назначается внешне через `REUSE.toml` и отражается в `frozen-spdx-mapping.json` с исходным SHA-256 и защищающими манифестами.

Это сохраняет научную воспроизводимость и одновременно делает назначение лицензии машиночитаемым.

Исходный `frozen-spdx-mapping.json` сохраняется как историческая таблица и задним числом не переписывается. Обнаруженные записи со смешанной основой вычисления SHA для разных окончаний строк и последующее расширение защищённого множества оформляются отдельными файлами коррекции `frozen-spdx-mapping-correction-v1.json` и `frozen-spdx-mapping-correction-v2.json`. Коррекции перечисляют каждый путь явно, связывают прежнюю контрольную сумму с SHA канонического объекта Git и не разрешают универсальный резервный допуск по окончаниям строк.

`licensing/repository-license-manifest.json` имеет другой жизненный цикл: это текущая изменяемая лицензионная опись репозитория. Она перестраивается для текущего состояния Git и не служит научной фиксацией.
