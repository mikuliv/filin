# Зафиксировано подтверждающие материалы и лицензирование без изменения байтов

Защищённый набор строится существующим `tools.docs.documentation_v2.build_protected_set`. Этап не добавляет комментарии SPDX в такие файлы и не изменяет их байты. Лицензия назначается внешне через `REUSE.toml` и отражается в `frozen-spdx-mapping.json` с исходным SHA-256 и protecting manifests.

Это сохраняет научную воспроизводимость и одновременно делает назначение лицензии машиночитаемым.
