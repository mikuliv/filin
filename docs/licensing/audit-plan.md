# План технического лицензионного аудита

Последовательность: предварительная проверка и защищённое исходное состояние; идентичности Git и происхождение файлов; статические ресурсы; объявления зависимостей Python и состав локального окружения; контейнеры и системные пакеты; REUSE и официальные тексты; профили, уведомления, манифест и SBOM; положительная и отрицательная кампании; регрессия проекта; один итоговый коммит.

Любое значение `review_required` переводит результат в режим только для аудита и устанавливает `release_ready=false`.
