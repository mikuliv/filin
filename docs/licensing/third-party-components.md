# Сторонние компоненты

Авторитетный человекочитаемый перечень создаётся в корневом `THIRD_PARTY_NOTICES.md` из реестров Python и контейнеров. Наличие зависимости в перечне не означает её включение в распространяемые исходные материалы и не изменяет исходную лицензию правообладателя.

Suricata, стек Elastic, Zeek, Docker Desktop, базовые образы и системные пакеты рассматриваются отдельно от собственного кода.
