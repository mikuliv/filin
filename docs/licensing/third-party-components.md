# Сторонние компоненты

Авторитетный человекочитаемый перечень генерируется в корневом `THIRD_PARTY_NOTICES.md` из Python и container registries. Наличие зависимости в перечне не означает её включение в source distribution и не изменяет исходную лицензию правообладателя.

Suricata, Elastic stack, Zeek, Docker Desktop, base images и системные packages рассматриваются отдельно от собственного кода.
