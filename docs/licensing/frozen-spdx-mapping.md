# Сопоставление SPDX для защищённых файлов

Машинная таблица `frozen-spdx-mapping.json` является сохранённым историческим слоем назначения лицензий защищённым файлам. Для каждого файла она содержит путь, SHA-256, тип, лицензионное выражение, правообладателя и профиль распространения. Заголовки в защищённые байты не добавляются.

Коррекции основы вычисления SHA и новые записи не переписывают эту таблицу: они находятся в версионированных файлах `frozen-spdx-mapping-correction-v1.json` и `frozen-spdx-mapping-correction-v2.json`. Эффективное отображение образуется только из исходной записи и явно принятой записи коррекции с проверяемым происхождением. Канонический SHA вычисляется по исходным байтам объекта Git.
