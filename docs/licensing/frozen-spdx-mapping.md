# Сопоставление SPDX для защищённых файлов

Машинная таблица `frozen-spdx-mapping.json` создаётся динамически из актуального множества защищённых файлов. Для каждого файла она содержит путь, SHA-256, тип, лицензионное выражение, правообладателя и профиль распространения. Заголовки в защищённые байты не добавляются.
