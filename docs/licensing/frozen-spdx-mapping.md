# Сопоставление SPDX для защищённых файлов

Машинная таблица `frozen-spdx-mapping.json` является сохранённым историческим слоем назначения лицензий защищённым файлам. Для каждого файла она содержит путь, SHA-256, тип, лицензионное выражение, правообладателя и профиль распространения. Заголовки в защищённые байты не добавляются.

Коррекции basis и новые записи не переписывают эту таблицу: они находятся в `frozen-spdx-mapping-correction-v1.json`. Эффективное отображение образуется только из исходной записи и явно принятой correction-записи с проверяемым provenance. Канонический SHA вычисляется по raw Git blob.
