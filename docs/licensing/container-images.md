# Контейнерные ссылки

Инвентаризируются все `FROM`, ссылки Compose `image:`, команды установки системных пакетов и ссылки GitHub Actions. Служба Docker опрашивается только через локальную команду `docker image ls`; загрузка не выполняется. Отсутствующий образ получает статус `not_available_offline`, но не `verified`.

Изменяемые ссылки сохраняются как результаты проверки. Исторические зафиксированные файлы не исправляются; вместо этого они исключаются из распространяемого комплекта. Машинный реестр: `container-images.json`.
