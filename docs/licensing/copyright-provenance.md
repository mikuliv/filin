# Происхождение и правообладание

Этап исходит из подтверждённых владельцем проекта обстоятельств: проект создан по личной инициативе, без служебного задания, договора, гранта, передачи прав и сознательного импорта стороннего исходного кода. Подтверждённое публичное имя — Руслан Покатилов.

Вся история всех Git refs проверяется инструментом `audit_git_authors`; первое появление каждого tracked-файла — `audit_file_provenance`. Технический результат не исключает сведений вне Git и не заменяет юридическую проверку.
