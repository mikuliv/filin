# Аудит статических ресурсов

Проверка охватывает изображения, SVG как XML и изображение, шрифты, JavaScript и CSS, включая признаки minification, source map, copyright/license metadata. В текущем tracked-составе растровые изображения и шрифты отсутствуют; единственные JS/CSS относятся к собственному интерфейсу.

Машинный результат: `static-assets-audit.json`.
