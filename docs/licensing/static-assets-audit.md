# Аудит статических ресурсов

Проверка охватывает изображения, SVG как XML и изображение, шрифты, JavaScript и CSS, включая признаки минимизации, карты исходного кода и метаданные авторских прав и лицензий. В текущем составе отслеживаемые растровые изображения и шрифты отсутствуют; единственные файлы JavaScript и CSS относятся к собственному интерфейсу.

Машинный результат: `static-assets-audit.json`.
