# Добавление этапа

1. Убедитесь, что этап разрешён машиночитаемым статусом.
2. Зафиксируйте протокол до реализации и оценки.
3. Зафиксируйте опорные идентификаторы, область применимости, контрольные условия, условия остановки и запреты.
4. Выполните кампанию без скрытой адаптации.
5. Создайте результат политики, манифест, отделённую SHA, реестр и сводку.
6. Добавьте protocol/report indexes.
7. Обновите статус YAML только по зафиксированному результату.
8. Обновите текущую документацию и ограничения без изменения исторических подтверждающих материалов.

`completed` и `passed` должны храниться раздельно. Одна документация не создаёт этап.
