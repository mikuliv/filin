# Контракт `shadow_event_v2`

Контракт пассивного события (`shadow_event_v2`) учитывает идентичность кандидата и задаёт структуру локального пассивного контура v0.3.15.5.1. Он не заменяет и не изменяет исторический `shadow_event_v1`.

Схема JSON проверяет структуру, тип события, идентификаторы, причинный порядок, ссылки на прогноз и среду выполнения, а также минимальную полезную нагрузку. Авторизация кандидата выполняется отдельно по зафиксированному реестру `candidate_registry_v1` и его каноническому обязательству. Список разрешённых значений кампании допускает только `v03154:65a3dd912d845bc1`; неявный переход между v1 и v2 запрещён.

Контракт не разрешает исходные векторы признаков, метки, IP- и MAC-адреса, имена узлов, содержимое сетевого пакета, учётные данные или абсолютные локальные пути. Все события пассивны и не имеют полномочий выполнять сетевые блокировки или автоматические действия.
