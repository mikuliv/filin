# Контракт среды выполнения локального теневого испытания

Контракт определяет последовательную обработку закрытых причинно упорядоченных окон без подключения к промышленной среде. Источником телеметрии остаётся неизменный `shadow_event_v1` версии v0.3.14.

Для каждого оценённого окна координатор фиксирует контрольную сумму PCAP по SHA-256, результат Zeek, неизменяемый идентификатор строки, строку из 51 признака, причинный порядок, псевдонимный ключ активности, зафиксированный прогноз, хеш последнего события, подтверждение доставки и атомарную контрольную точку. Метки в контрольной точке отсутствуют.

Доставка выполняется не менее одного раза. Получатель обязан устранять дубликаты по `idempotency_key`; доставка строго один раз не заявляется. Очередь и буфер ограничены, предупреждение и рассмотрение имеют приоритет, каждый отброшенный элемент учитывается. Ошибка транспорта не вправе изменять прогноз, конечный автомат, причинный порядок или пороговые значения.

Контракт среды выполнения запрещает внешние URL, промышленные учётные данные, запись в серверную часть, сеть узла, изменение межсетевого экрана и автоматическое применение решений. Все события проходят проверку по схеме JSON, а также проверки конфиденциальности и минимизации данных.
