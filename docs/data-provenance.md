# Происхождение данных

## Источники

Наблюдения клиента формируются `traffic-client` и используются только как отдельный контрольный источник. Наблюдения сенсора проходят цепочку:

```text
PCAP → журналы Zeek → анализатор Zeek → нормализованные события сенсора → сопоставление по маркеру → network_sensor_v0_3
```

События `network_sensor_v0_3` формируются только из фактически захваченного сетевого трафика. События клиента нужны для контрольного сравнения и не являются источником событий Zeek или сетевых признаков.

Для v0.3.15.4–v0.3.15.5 действует отдельное ограничение: пакеты PCAP непосредственно созданы зависящим от класса шаблоном Scapy, а не захвачены при работе Docker-клиента против целевого сервиса. Docker на этих стадиях использован для Zeek. Поэтому подтверждена цепочка `PCAP → Zeek → признаки`, но не происхождение от реального обмена клиента с сервисом; см. [переоценку методологии](experiments/v0_3_15_4_v0_3_15_5_methodology_reassessment.md).

## Маркеры и интервалы

Каждое выполнение получает реальные начальный и конечный HTTP-маркеры внутри лабораторной сети. Они задают полуоткрытый интервал сенсора `[start, end)`. Маркеры используются только для сопоставления и исключаются из признаков модели. Сопоставление не использует метку, ожидаемые признаки или готовые признаки клиента.

## Контроль происхождения

Роли кампании разделяют запуски обучения, проверки и оценки устойчивости. Для PCAP, журналов Zeek, нормализованных событий и наборов данных сохраняются SHA-256. Проверки происхождения, разбиения и дубликатов подтверждают отсутствие пересечений и полей утечки. Исходные адреса IP, имена узлов, URI, UID Zeek, метаданные маркера, метка и идентификаторы выполнения не являются признаками модели.

## Будущий независимый корпус

Новый технический путь предусматривает отдельные события выполнения и маркеров,
манифесты захвата, SHA-256 PCAP, состояние Zeek и отчёт реализации параметров.
Запрошенные значения сравниваются с наблюдаемыми значениями Zeek; недоступное
измерение фиксируется как `not_observable`, а не копируется из конфигурации.
Манифест связывается с выполнением и проверяет непустой PCAP, число пакетов,
размер и SHA-256.

Корпус по этому пути ещё не собран. В репозитории нет новых PCAP, журналов Zeek,
таблиц признаков, меток, прогнозов или результатов метрик этой проверки.
