# Исторические ограничения

Исторические stages фиксировали environment mismatch, insufficient coverage,
episode-policy failures, contract incompatibility, incomplete ACK/privacy evidence,
performance failures, clock-domain ambiguity и bundle integrity findings.

Эти ограничения не удаляются после corrections. Точные формулировки находятся в
соответствующих policy results и known-limitations files через [reports index](../reports/index.md).

Для текущей архитектуры используйте [current limitations](../architecture/limitations.md).
