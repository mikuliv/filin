# Модель безопасности лабораторного стенда

Стенд использует изолированную сеть Docker и перечень разрешённых локальных целей. Сценарии представляют низкоинтенсивные имитации и не используют внешние адреса, реальные учётные данные, вредоносное ПО или полезные нагрузки настоящих эксплойтов. `nmap` и `masscan` запрещены.

Аудит захвата проверяет отсутствие внешних целей. Лабораторные данные и результаты не следует переносить в производственную инфраструктуру без отдельной методики, данных и проверки.
