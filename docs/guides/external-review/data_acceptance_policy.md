# Порядок приёма данных

> Русское изложение [зафиксированной политики](../../external_review/data_acceptance_policy.md). Машинные правила исходного пакета имеют приоритет.

## До приёма

Должны быть определены владелец материала, правовое основание, область использования, формат, схема, период наблюдения, состав полей, правила обезличивания, способ передачи и срок хранения. Идентификаторы выборки и контрольные суммы фиксируются до оценивания.

## Минимальные требования

Материал должен соответствовать утверждённой схеме, иметь проверяемое происхождение, однозначные временные границы, согласованную систему меток и отсутствие неразрешённых секретов либо персональных сведений. Дубликаты, пропуски, нечисловые значения и отклонения состава классов отражаются явно.

## Основания отклонения

Данные отклоняются при неизвестном происхождении, повреждении, несовпадении контрольной суммы, нарушении схемы, преждевременном раскрытии меток, отсутствии разрешения, пересечении с обучающим материалом или невозможности воспроизвести состав выборки.

Принятие данных не разрешает запуск испытания: оно только фиксирует пригодность конкретного входного пакета для последующего независимого решения.
