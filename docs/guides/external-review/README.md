# Независимая проверка: русская версия для чтения

## Назначение

Этот каталог содержит актуальное русское изложение зафиксированного пакета независимой проверки v0.3.18. Исходные материалы в [`docs/external_review`](../../external_review/README.md) входят в защищённый манифест и сохраняются побайтово. Настоящие страницы помогают читать пакет, но не заменяют исходники при проверке контрольных сумм.

Этап v0.3.18 подтвердил только воспроизводимость синтетической репетиции процедуры. Научное подтверждение отсутствует (`scientific_evidence=false`). Реальные данные, организация и модель не использовались. Следующая допустимая работа ограничена независимым рассмотрением пакета и согласованием плана испытания.

Запрещены фактическое внешнее испытание, сбор реального трафика, теневой режим, подключение к серверной части, промышленная эксплуатация, реальные уведомления, автоматическое воздействие и блокировка сети.
