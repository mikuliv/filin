# Руководство по воспроизводимости

> Русское изложение [зафиксированного руководства](../../external_review/reproducibility_guide.md).

## Назначение

Автономная проверка подтверждает, что переданный пакет цел, однозначно сериализован и даёт те же агрегированные результаты в чистом каталоге. Она не подтверждает качество модели на иных данных.

## Подготовка

Используется отдельная копия пакета без Git, сети и серверной части. Проверяющий фиксирует версию Python, операционную систему, контрольную сумму архива и точную команду запуска. Запрещены загрузка зависимостей и обращение к внешним службам.

## Порядок действий

1. Проверить состав пакета и корневую контрольную сумму.
2. Проверить схемы и контрольные суммы каждого материала.
3. Запустить автономное средство проверки только с локальными входами.
4. Сопоставить код завершения, стандартный вывод и ошибки с ожидаемыми.
5. Повторить запуск в новом чистом каталоге.
6. Сравнить полученные байты, показатели и журнал проверки.

## Каноническое представление

Для машинных документов применяются фиксированная кодировка, устойчивый порядок ключей, однозначные разделители и отсутствие зависящих от машины абсолютных путей. Время создания и иные переменные поля не должны менять смысловую контрольную сумму.

## Остановка

Проверка не пройдена при отсутствующем файле, неверной контрольной сумме, расхождении схемы, сетевом обращении, зависимости от Git, недетерминированном результате или несовпадении повторного запуска. Причина записывается, а исходный пакет не исправляется на месте.
