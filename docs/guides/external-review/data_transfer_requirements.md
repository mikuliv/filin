# Требования к передаче данных

> Русское изложение [зафиксированных требований](../../external_review/data_transfer_requirements.md).

До передачи фиксируются отправитель, получатель, перечень файлов, контрольные суммы, объём, назначение, способ шифрования и срок доступности канала. Секрет для расшифрования передаётся отдельно.

Передача выполняется только по согласованному защищённому каналу с проверкой личности получателя. Публичные ссылки, общие каталоги без разграничения доступа и пересылка секретов вместе с архивом запрещены.

После получения принимающая сторона повторно вычисляет контрольные суммы, подтверждает комплектность и регистрирует время приёма. Повреждённый или неполный пакет изолируется и не используется.

При ошибке создаётся новая передача с новой записью; прежний пакет не заменяется незаметно.
