# Руководство оператора испытания

> Русское изложение [зафиксированного руководства](../../external_review/trial_operator_guide.md).

## Назначение роли

Оператор выполняет только утверждённый план, используя зафиксированные кандидат, входы и среду. Он не видит эталонные метки, не меняет критерии и не утверждает итог.

## Подготовка

Оператор проверяет идентичность кандидата, контрольные суммы входов, версию среды, отсутствие сети, доступность места для результатов и запрет произвольных команд. План и параметры должны быть зафиксированы до запуска.

## Порядок действий

1. Проверить входной манифест и ограничения доступа.
2. Запустить только разрешённую процедуру в изолированной среде.
3. Сохранить стандартный вывод, ошибки, код завершения и журнал времени.
4. Зафиксировать прогнозы канонически и вычислить их контрольную сумму.
5. Передать подтверждение фиксации хранителю разметки.
6. Передать неизменяемый пакет прогнозов независимому оценщику.

## Запреты

Нельзя подбирать пороги по скрытым меткам, повторять запуск ради улучшения результата, менять строки входа, заменять кандидата, использовать сеть, обращаться к производственной системе или выполнять автоматическое воздействие.

## Остановка

Запуск прекращается при несовпадении контрольной суммы, недоступности утверждённой среды, сетевой попытке, ошибке сериализации, неполном результате или признаке раскрытия меток. Повтор допускается только как новая документированная попытка.
