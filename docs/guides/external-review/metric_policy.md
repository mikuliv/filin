# Политика расчёта метрик

> Русское изложение [зафиксированной политики](../../external_review/metric_policy.md). Авторитетные названия полей сохраняются в машинных контрактах.

## Обязательные результаты

Отчёт должен показывать объём выборки, состав классов, матрицу ошибок, точность, полноту и меру F1 по каждому классу, макроусреднённые значения, долю ложных срабатываний, долю отказов от решения и число отсутствующих прогнозов. Для эпизодов результаты приводятся отдельно от результатов по отдельным событиям.

## Порядок расчёта

Сначала проверяются идентификаторы и полнота сопоставления, затем строятся исходные счётчики и только после этого агрегаты. Нулевые знаменатели, малые группы и отсутствующие классы отражаются явно; их нельзя скрывать усреднением.

## Запрещённые действия

После раскрытия меток нельзя выбирать другой порог, исключать неудобные строки, менять состав классов, подбирать способ усреднения, объединять категории или повторять запуск для получения лучшего значения.

Если критерий принятия не был зафиксирован заранее, метрика остаётся описательной и не может самостоятельно дать положительное решение.
