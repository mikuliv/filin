# Воспроизводимость лабораторных запусков

`execution_id` различает физические выполнения. `run_semantic_id` вычисляется из канонического замороженного плана и не включает время, идентификатор процесса, пользователя, имя узла или временный путь.

Уровни: `byte_identical`, `semantic_identical`, `contract_equivalent`, `differences_observed`, `not_reproducible`. Последний уровень является отрицательным результатом обязательной группы воспроизведения и никогда не скрывается.

После первого исполнения план заморожен. Комплект среды выполнения содержит план, привязки, снимки окружения и зависимостей, результат, индекс артефактов, манифест и отдельный SHA-хэш. SQLite хранит только индекс, статусы, аудит и ручной изменяемый слой.
