# Воспроизводимость лабораторных запусков

`execution_id` различает физические выполнения. `run_semantic_id` вычисляется из канонического замороженного плана и не включает время, PID, пользователя, hostname или временный путь.

Уровни: `byte_identical`, `semantic_identical`, `contract_equivalent`, `differences_observed`, `not_reproducible`. Последний уровень является отрицательным результатом обязательной replay-группы и никогда не скрывается.

После первого исполнения план заморожен. Runtime bundle содержит план, привязки, снимки окружения и зависимостей, результат, индекс артефактов, manifest и detached SHA. SQLite хранит только индекс, статусы, audit и ручной overlay.
