# Сопоставление конкурирующих гипотез v0.4.2

Анализ принимает только проверенный temporal bundle v0.4.1 и frozen-каталог из 31 декларативного правила. Гипотезы относятся к одному аналитическому вопросу и области рассмотрения. Модельный результат и MITRE-контекст сами по себе не подтверждают злонамеренность.

Профиль обоснованности содержит прозрачные счётчики без вероятностей и скрытых весов. Канонический источник учитывается один раз. Равная поддержка сохраняется без технического ранжирования по идентификатору. Вопросы специалисту требуют ручного рассмотрения и имеют статус `not_executed`.

Автономная проверка не использует Git, сеть, модель или backend. CRLF/LF нормализуются только для текстовых артефактов manifest.
