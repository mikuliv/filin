# Критерии приёмки Phase 1

Числа ниже взяты из `lab/network_validation/config/acceptance_criteria.json`; этот файл является авторитетным контрактом. Поля контракта сейчас `sealed=false`, поэтому критерии известны заранее, но ещё не применялись к научному корпусу.

| Критерий | Требование |
|---|---:|
| macro-F1 кандидата | не ниже 0.80 |
| FPR | не выше 0.05 |
| полнота каждого класса | не ниже 0.65 |
| падение macro-F1 на невидимом семействе генератора | не более 0.10 |
| падение macro-F1 на невидимой инфраструктуре | не более 0.10 |
| падение macro-F1 на невидимой цели | не более 0.10 |
| отрыв от исходного уровня только по инфраструктуре | не менее 0.15 |
| отрыв от исходного уровня по портам и сервисам | не менее 0.10 |
| отрыв от исходного уровня по темпу трафика | не менее 0.05 |
| реализация заданных параметров | не ниже 0.95 |
| контрфактуальные пары | не ниже 0.90 |
| внешняя выборка | обязательна |
| macro-F1 на внешней выборке | не ниже 0.70 |
| FPR на внешней выборке | не выше 0.10 |
| полнота класса на внешней выборке | не ниже 0.55 |
| доля исключённых строк | не выше 0.02 |
| доля неразрешённых обязательных параметров | ровно 0 |

До раскрытия эталонной разметки фиксируются применимый артефакт модели, прогнозы, контрольная сумма строк прогнозов, журнал исключений и конфигурация оценки. Затем создаётся разрешающая запись раскрытия. Только после этого метки становятся доступны оценщику и рассчитываются зависящие от них macro-F1, FPR, полнота по классам, контрфактуальные и остальные научные метрики. Фиксация прогнозов, раскрытие разметки и расчёт метрик — три разные стадии.

Точная последовательность предпосылок берётся из `lab/network_validation/execution/label_vault_contract.json`: `frozen_predictions` → `frozen_prediction_row_digest` → `frozen_exclusion_ledger` → `authorized_unlock_record` → `labels_unlocked` → `scientific_metrics_calculated`. Настройка по `blind_internal_holdout` запрещена. Неудача любого обязательного критерия блокирует продвижение; отсутствие результата внешней выборки блокирует положительный научный вывод. Такой вывод не является разрешением на промышленную эксплуатацию.

## Исходные ориентиры и отрицательные результаты

Сравнение включает большинство, только сервисы и порты, только темп, только HTTP, только временные признаки, только скользящие признаки, диагностические признаки инфраструктуры и семейства, неглубокое дерево, логистическую регрессию и зафиксированного кандидата. Исторические результаты не переносятся на этот план. Пока нет выполненных сессий, ни один критерий не имеет результата.
