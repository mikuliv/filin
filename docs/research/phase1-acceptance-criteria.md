# Критерии приёмки Phase 1

Числа ниже взяты из `lab/network_validation/config/acceptance_criteria.json`; этот файл является авторитетным контрактом. Поля контракта сейчас `sealed=false`, поэтому критерии известны заранее, но ещё не применялись к научному корпусу.

| Критерий | Требование |
|---|---:|
| macro-F1 кандидата | не ниже 0.80 |
| FPR | не выше 0.05 |
| полнота каждого класса | не ниже 0.65 |
| падение macro-F1 на невидимом семействе генератора | не более 0.10 |
| падение macro-F1 на невидимой инфраструктуре | не более 0.10 |
| падение macro-F1 на невидимой цели | не более 0.10 |
| отрыв от baseline только по инфраструктуре | не менее 0.15 |
| отрыв от baseline по портам и сервисам | не менее 0.10 |
| отрыв от baseline по темпу трафика | не менее 0.05 |
| реализация заданных параметров | не ниже 0.95 |
| контрфактуальные пары | не ниже 0.90 |
| внешняя выборка | обязательна |
| macro-F1 на внешней выборке | не ниже 0.70 |
| FPR на внешней выборке | не выше 0.10 |
| полнота класса на внешней выборке | не ниже 0.55 |
| доля исключённых строк | не выше 0.02 |
| доля неразрешённых обязательных параметров | ровно 0 |

Оценка проводится после фиксации прогнозов и до раскрытия разметки. Настройка по `blind_internal_holdout` запрещена. Неудача любого обязательного критерия блокирует продвижение; внешняя выборка блокирует научный pass при отсутствии результата. Научный pass не является разрешением промышленную эксплуатацию.

## Baseline и отрицательные результаты

Сравнение включает большинство, только сервисы и порты, только темп, только HTTP, только временные признаки, только скользящие признаки, диагностические признаки инфраструктуры и семейства, неглубокое дерево, логистическую регрессию и зафиксированного кандидата. Исторические результаты не переносятся на этот план. Пока нет выполненных сессий, ни один критерий не имеет результата.
