# Временные и структурные отношения v0.4.1

Слой принимает только проверенный `incident_reconstruction_bundle_v1` и
формирует нормализованные значения времени, интервалы, отношения, группы,
разрывы и ацикличный граф реконструкции.

Время сетевого наблюдения отделено от времени формирования, приёма, доставки и
сериализации. Точность исходной отметки сохраняется; неопределённый интервал не
сжимается в точку. Идентификатор используется как технический tie-break только
для канонической сериализации.

Структурное отношение создаётся лишь при явном основании: общем passive event,
наблюдаемом субъекте или другом заранее зафиксированном правиле. Одинаковый
класс модели, близкое время, MITRE-сопоставление или похожая гипотеза сами по
себе связью не являются. Группа корреляции не называется подтверждённым
инцидентом.

Каждое отношение имеет машинно проверяемое объяснение. Разрывы фиксируют
отсутствующие границы, конфликтующие часы и недостающие материалы, не создавая
вместо них наблюдаемые факты.

Автономная проверка не использует Git, сеть, модель или backend. Ограничение
исходного этапа: при `core.autocrlf=true` старый validator v0.4.0 сравнивает
рабочие CRLF-байты с LF-checksum Git-объектов. Официальные значения v0.4.0
проверены непосредственно по неизменяемым Git-объектам; новый manifest применяет
явную нормализацию CRLF в LF.
