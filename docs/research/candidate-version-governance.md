# Управление версиями кандидатов

Каталог v0.4.5 доступен только для чтения и строится из существующих реестр и manifests. Он не создаёт кандидатов, копий модели или новых идентификаторов.

Полностью пригоден к replay один действующий Зафиксировано-кандидат. Исторический кандидат использует несовместимый контракт и не имеет доступного подтверждённого артефакта, поэтому межкандидатное сравнение не выполняется. Это не блокирует сравнение повторных запусков текущего кандидата.
