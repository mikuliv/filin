# Управление версиями кандидатов

Каталог v0.4.5 доступен только для чтения и строится из существующих реестра и манифестов. Он не создаёт кандидатов, копий модели или новых идентификаторов.

Полностью пригоден к воспроизведению один действующий зафиксированный кандидат. Исторический кандидат использует несовместимый контракт и не имеет доступного подтверждённого артефакта, поэтому межкандидатное сравнение не выполняется. Это не блокирует сравнение повторных запусков текущего кандидата.
