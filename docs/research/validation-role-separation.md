# Разделение ролей проверки

Контур использует роли `control_data_custodian`, `inference_operator`, `evaluation_operator`, `validation_reviewer` и `observer`. Каждая роль получает отдельный непрозрачный capability token и allowlist операций; администраторского обхода нет.

Один человек может технически исполнять разделённые роли, поэтому это не является независимой человеческой проверкой. Статус v0.4.7 — `role_separated_blind`, число независимых рецензентов — ноль.
