# Покрытие поведения Filin `vNext`: первая волна

## Назначение отчёта

Отчёт фиксирует только инженерную исполнимость первой волны. Все выполненные записи имеют статус `implemented`; ни одна не имеет статуса `experimentally_validated`. Точность, полнота обнаружения и иные научные показатели не вычислялись.

Фактически доступны `network.flow`, `http.request` и `auth.attempt`, полученные на одноразовом локальном стенде. `dns.query` для обратного вызова и несколько независимых источников пока недоступны.

## Семейства генераторов

Реестр возможностей содержит 11 записей: восемь исполняемых генераторов, один запланированный генератор `DNS` и два неизменённых запланированных адаптера старых генераторов. Реальные независимые пары существуют для разведки, злоупотребления реквизитами и обратных вызовов. Отдельные `WebEnumerationGenerator` и `BenignOperationsGenerator` не выдаются за вторые семьи.

## Фактически проверенный поток

Для каждого из 22 реализованных сценариев выполнены локальный вызов, запись `JSONL`, вычисление `SHA-256` сырого артефакта, преобразование `parsed` → `normalized`, проверка типизированного события и сборка `ObservationBundle`. Получены только `network.flow`, `http.request` и `auth.attempt`. Временные результаты удалены после проверки.

Проверки альтернативных объяснений сопоставили `periodic_beacon` с `health_checks`, `service_discovery` с `approved_scanner` и `brute_force` с `auth_misconfiguration`. В каждой паре пересекается минимум один тип наблюдаемой телеметрии, а различающая разметка таксономии присутствует только во внешнем изолированном слое.

## Утечки и границы вывода

Проверки запрещают поля истинной разметки и идентификаторы `scenario`, `generator` и `realization` в сырых записях, нормализованных событиях, метаданных выполнения и пакетах наблюдений. Отдельно проверяется отсутствие специальных названий Filin, адресов, заголовков, имён пользователей и портов отдельного класса. Истинная разметка не передаётся генератору и не включается в пакет наблюдений.

Локальная инженерная проверка подтверждает техническую целостность контура. Она не доказывает репрезентативность поведения, независимость данных, качество признаков или обнаружения.
