# Визуальный интерфейс лабораторной консоли

Интерфейс v0.4.3.1 построен как presentation layer над существующими adapters, contracts и services. Он не переносит бизнес-логику в шаблоны и не изменяет исходные исследовательские артефакты.

## Структура

`lab_console/presentation` преобразует технические структуры в отдельные view models. `base.html` задаёт общий sidebar, верхнюю панель и область содержимого. Шаблоны страниц отвечают только за конкретный операторский вопрос. Локальные CSS, JavaScript и SVG не обращаются к внешним CDN, шрифтам или сервисам.

Ключевые визуализации:

- timeline разделяет наблюдения, интервалы, неопределённость и разрывы;
- reconstruction graph показывает факты, интервалы, группы, разрывы и гипотезы структурными рёбрами без причинных стрелок;
- шесть гипотез представлены нейтральными карточками без победителя;
- матрица 6×6 объясняет выбранную ячейку и не является рейтингом;
- показатели модели всегда содержат этап, набор, источник и ограничение.

## Безопасность представления

Авторизация, CSRF, security headers, SQLite review-overlay и allowlist task runner сохранены. Jinja2 продолжает экранировать пользовательский текст. Полный JSON закрыт по умолчанию, ограничен по высоте, форматирован, доступен для поиска и копирования. Внешние ресурсы и unsafe inline scripts отсутствуют.

## Адаптивность

Страница не создаёт горизонтальную прокрутку при 1366×768; широкие таблицы используют локальный контейнер. Карточки переносятся, sidebar сворачивается, граф занимает доступную область. При эффективной области масштаба 125% горизонтального переполнения страницы также нет.
