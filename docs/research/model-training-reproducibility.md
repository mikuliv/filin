# Воспроизводимость обучения v0.4.6

Safe модуль запуска выполняет только встроенный Перечень разрешённых значений рецепт `hgb-multiclass-v046-r1` внутри процесса Python. Сеть, shell, произвольные модули, команды, пути, AutoML и подбор параметров запрещены.

Каждое выполнение имеет уникальный execution ID и детерминированный training Семантический идентификатор. Сравниваются параметры, порядок признаков, классы, прогнозы, Побайтовая контрольная сумма и модель семантический отпечаток. Незавершённый binary не принимается; после перезапуска оператор явно архивирует частичный результат или повторяет Зафиксировано execution.

Модельный binary остаётся в `runtime/lab_console/v0_4_6/` и не включается в Git или экспорт. подтверждающие материалы содержит только безопасные манифест/fingerprint сведения.
