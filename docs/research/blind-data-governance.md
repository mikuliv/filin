# Управление слепыми контрольными данными

Control pack хранится только в runtime, не содержит реальных, персональных или организационных данных и имеет отдельные opaque session/capture identities. Overlap gate проверяет file, semantic, session, capture, scenario, seed, event, normalized-row, temporal, derived-copy и template domains.

Исходные строки, labels и prediction rows не входят в Git и evidence bundle.
