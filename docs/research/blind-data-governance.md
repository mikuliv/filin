# Управление слепыми контрольными данными

контрольный набор хранится только в среда выполнения, не содержит реальных, персональных или организационных данных и имеет отдельные opaque session/capture identities. проверка отсутствия пересечений проверяет file, semantic, session, capture, scenario, seed, event, normalized-row, temporal, derived-copy и template domains.

Исходные строки, labels и prediction rows не входят в Git и комплект подтверждающих материалов.
