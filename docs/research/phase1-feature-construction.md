# Построение 51 признака Phase 1

## Авторитетные источники

Порядок и число полей задаёт `ml/experiments/v0_3_15_4/feature_contract_v2.yaml`. Формулы реализованы в `ml/features/v034_profiles.py` и `ml/features/network_sensor_v0_5.py`; адаптер сетевой процедуры находится в `lab/network_validation/feature_adapter.py`. Эта страница объясняет контракт и не заменяет код.

Все значения — конечные числа. Базовые признаки получают из `conn.log`, `http.log` и `dns.log`; временные признаки используют состояние предыдущих окон, очищенное при смене `run_id`; контекстные признаки используют наблюдаемые поля текущего окна. Маркерные строки и метаданные ослепления не являются входом.

## Происхождение и запреты

Первые 16 полей и отдельные контекстные поля получают прямое наблюдение; остальные — детерминированный вывод из наблюдаемых строк и состояния окон. Для каждой строки формируется сопроводительный файл происхождения, который не является входом модели. Разметка и полезная нагрузка в него не добавляются.

Если обязательный параметр нельзя подтвердить, используется явное отсутствие или `unsupported`, а не догадка. Временная копия журналов нужна только для удаления строк с маркером; исходные PCAP и Zeek-файлы остаются неизменными.
