# Локальная лабораторная консоль

Консоль v0.4.3 — отдельный пакет `lab_console`, развиваемый в `main`. Исторический `backend` не используется и не изменяется. Консоль связывает read-only adapters, проверку целостности, серверные Jinja2-страницы, локальный API, SQLite-состояние, ручное рассмотрение и диспетчер разрешённых задач.

По умолчанию Uvicorn слушает только `127.0.0.1:8043`. Внешнее связывание отклоняется; исключение существует только для явно включённого development mode и не разрешает публикацию. Интерфейс не использует CDN, телеметрию или внешние запросы.

## Страницы

Главная панель, этапы, модели, результаты модели, комплекты, карточки инцидентов, временная шкала, граф, гипотезы, сопоставления, вопросы, ручное рассмотрение, задачи, тесты, журналы и состояние системы. Основная v0.3.x и лабораторная v0.4.x линии показаны раздельно. Все показатели сопровождаются лабораторным контекстом и источником.

## Модель безопасности

Вход выполняется по длинному локальному токену `FILIN_CONSOLE_TOKEN`; сравнение постоянно по времени, cookie HttpOnly и SameSite Strict, срок сессии ограничен. Изменяющие API-запросы требуют JSON, действующую сессию и CSRF. Заголовки запрещают framing, MIME sniffing и внешние ресурсы. Заметки не принимают HTML. SQL параметризован.

Файлы доступны только по непрозрачному token из фиксированных корней. Проверяются `resolve`, выход за корень, symlink, расширение и размер; бинарники, базы, ключи и PCAP не выдаются.

## Диспетчер задач

Каталог `allowed_tasks_v1.yaml` заморожен и имеет SHA-256. HTTP передаёт только `task_id` и подтверждение: аргументы и cwd нельзя изменить. Процессы запускаются массивом argv с `shell=False`, ограниченными environment, параллельностью, timeout и логом. Сохраняются HEAD, tree state, PID, exit code и SHA каталога. Незавершённые записи после рестарта становятся `orphaned`.

Консоль лабораторная, не production: нет backend/SIEM integration, обучения, загрузки модели, сетевого сбора, уведомлений, блокирования или автоматического реагирования.
