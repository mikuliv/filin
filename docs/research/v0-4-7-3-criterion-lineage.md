# Происхождение критериев v0.4.7.3

Карта содержит 48 обязательных критериев: 24 сохранённых требования v0.4.7 и 24 усиленных требования допуска v0.4.7.2. Ни один источник не потерян и ни один критерий не получил скрытого веса.

Шесть прежних провалов оцениваются отдельно на новом наборе. Для каждого сохраняются исходный идентификатор, требуемый порог, наблюдаемое значение, связанные корректирующие действия и ограничение синтетической применимости. Три проблемы предложения закрыты; три проблемы действующего кандидата остаются открыты.

Все обязательные критерии равноправны: один провал блокирует положительное решение. `not_assessable` также не может быть превращён в положительный результат. Порядок строк не является рейтингом и сравнение не выбирает победителя автоматически.
