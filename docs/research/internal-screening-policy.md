# Политика предварительная внутренняя проверка v0.4.6

предварительная проверка разрешается только после замораживания воспроизводимого предложение кандидата package. Критерии обязательные критерии допуска замораживаются до открытия предварительная проверка labels; после получения результата их нельзя менять, скрывать или сводить к winner score.

Действующий кандидат применяется только для чтения, предложение — через `proposal_evaluation_binding_v1`, а сравнение строится адаптером v0.4.5. Проверяются контракты, метрики, классы, ложноположительные результаты, отказ от решения, карточки, разрывы и гипотезы. Внутренняя синтетическая предварительная проверка не является внешней проверкой.

Для допуска все обязательные критерии должны иметь статус `passed`, включая завершённое ручное рассмотрение. Автоматическое решение запрещено.
