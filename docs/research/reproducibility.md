# Воспроизводимость

## Идентичность

Кандидат, контракт, протокол, комплект исходных материалов и результаты связываются SHA-256. Семантическая
контрольная сумма фиксирует значимое содержимое там, где байтовое представление может различаться.

## Детерминизм

Пространства начальных значений, канонические файлы JSON, устойчивый порядок и версионированные генераторы должны
давать одинаковые артефакты для одинаковых входных данных. Отметки времени среды выполнения и временные пути
не включаются в семантическую идентичность без необходимости.

## Проверяемая цепочка

1. протокол определяет запуск;
2. журнал запуска фиксирует выполнение;
3. результат политики фиксирует итог;
4. манифест перечисляет артефакты;
5. отделённая SHA фиксирует манифест;
6. реестр утверждений связывает утверждения с подтверждающими материалами;
7. руководство по воспроизведению даёт безопасную команду проверки.

## Ограничение

Воспроизводимость лабораторного результата не равна внешней валидности. Зафиксированный файл
нельзя исправлять задним числом; используются errata и новый обзор.
