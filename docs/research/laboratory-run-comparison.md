# Сравнение лабораторных запусков

Каждое сравнение начинается с проверка сопоставимости. `comparable` разрешает парные описательные дельты, `conditionally_comparable` — только явно ограниченное сопоставление, `not_comparable` блокирует итоговую дельту качества.

Сравниваются происхождение, выполнение, метрики, классы, эпизоды, passive events, реконструкция, карточки, разрывы и гипотезы. Карточки сопоставляются по semantic identity, история происхождения и canonical content, а не по случайному ID.

Результат `improved` не означает победу, допуск или промышленная эксплуатация. Скрытые веса, общий score и автоматическое продвижение запрещены.
