# Сравнение лабораторных запусков

Каждое сравнение начинается с проверки сопоставимости. `comparable` разрешает парные описательные изменения, `conditionally_comparable` — только явно ограниченное сопоставление, `not_comparable` блокирует итоговое изменение качества.

Сравниваются происхождение, выполнение, метрики, классы, эпизоды, пассивные события, реконструкция, карточки, разрывы и гипотезы. Карточки сопоставляются по семантической идентичности, истории происхождения и каноническому содержимому, а не по случайному идентификатору.

Результат `improved` не означает победу, допуск или разрешение на промышленную эксплуатацию. Скрытые веса, общая оценка и автоматическое продвижение запрещены.
