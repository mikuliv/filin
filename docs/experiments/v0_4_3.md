# Этап v0.4.3

Этап реализует локальную лабораторную консоль и расширенную проверяемую карточку инцидента. Frozen protocol revision 1 зафиксирован до официальной кампании. Кандидат, feature/event contracts, v0.4.0–v0.4.2 и дерево исторического `backend` не изменялись.

Проверяются localhost-only bind, token auth, сессии, CSRF, security headers, безопасные пути, строгий API, 16 JSON Schema, SQLite migrations, review-overlay, детерминированные card/view/export, allowlist task runner, restart/orphan recovery, redaction, отсутствие shell и внешних ресурсов.

Официальная синтетическая кампания содержит не менее 50 положительных и 120 отрицательных сценариев. Результаты и representative JSON находятся в `ml/reports/v0_4_3`. Консоль не подтверждает причинность или компрометацию, не выбирает победившую гипотезу и не выполняет автоматических действий.

Следующий допустимый лабораторный этап — только v0.4.4. Основная линия остаётся на v0.3.18 со следующим этапом v0.3.19.
