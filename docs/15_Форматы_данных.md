# Форматы данных

Основные переходы между форматами таковы:

| Артефакт | Назначение | Защита |
|---|---|---|
| PCAP | исходный захваченный трафик | размер, читаемость, SHA-256 |
| журналы Zeek | структурированные сетевые наблюдения | наличие `conn.log`, проверка схемы |
| строка признаков | 51 числовое значение в фиксированном порядке | конечность, порядок, SHA-256 схемы |
| prediction | результат замороженной оценки | candidate manifest и no-fit guard |
| canonical event | пассивное событие для доставки | каноническая сериализация и хэш |
| checkpoint | подтверждённые единицы доставки | атомарная запись |
| JSONL-журнал | последовательность событий кампании | цепочка контрольных сумм |

Ключи JSON, имена схем и события (`session_completed`, `execution_token`) не переводятся. Русское описание объясняет их назначение рядом с кодовым именем.
