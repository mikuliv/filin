# Установка и настройка

Поддерживаемая схема рассчитана на Fedora 44: установлены Git, Python, Docker Engine и Compose plugin. Сначала клонируют репозиторий и создают отдельное виртуальное окружение Python; зависимости берутся из `requirements.txt` соответствующего слоя. Секреты и каталоги исполнения создаются вне отслеживаемой части репозитория.

Проверку среды начинают без запуска кампании:

```bash
python --version
docker version
docker compose version
git status --short
```

Команды подтверждают версии и чистоту дерева. Если Docker недоступен, не следует обходить проверку запуском частей pipeline вручную: это создаёт результаты, которые нельзя считать evidence. Для локального smoke разрешены только диагностические проверки стенда и существующие documentation/unit tests.
