# Сторонние компоненты

| Компонент | Назначение | Источник и способ использования | Лицензия |
| --- | --- | --- | --- |
| Docker | Изолированный лабораторный среда выполнения и named volumes | Внешний среда выполнения, код не включается в репозиторий | Уточняется по дистрибутиву Docker |
| Zeek | Offline обработка фактического PCAP | Внешний container image/среда выполнения, код Zeek не включается | Уточняется по официальному дистрибутиву Zeek |
| scikit-learn | Pipeline baseline оценка | Python dependency проекта | Уточняется по файлам зависимостей и upstream |

Этот список описывает техническое использование, а не даёт юридический вывод. Условия распространения новой части проекта требуют отдельного уточнения. Наличие лицензии исторического компонента не означает автоматическое применение той же лицензии ко всем новым материалам без анализа структуры производного произведения.
