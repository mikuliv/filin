# Сторонние компоненты

| Компонент | Назначение | Источник и способ использования | Лицензия |
| --- | --- | --- | --- |
| Docker | Изолированная лабораторная среда и именованные тома | Внешняя среда выполнения; код не включается в репозиторий | Уточняется по дистрибутиву Docker |
| Zeek | Автономная обработка фактического PCAP | Внешний образ контейнера; код Zeek не включается | Уточняется по официальному дистрибутиву Zeek |
| scikit-learn | Базовый конвейер оценки | Зависимость Python проекта | Уточняется по файлам зависимостей и первичному источнику |

Этот список описывает техническое использование, а не даёт юридический вывод. Условия распространения новой части проекта требуют отдельного уточнения. Наличие лицензии исторического компонента не означает автоматическое применение той же лицензии ко всем новым материалам без анализа структуры производного произведения.
