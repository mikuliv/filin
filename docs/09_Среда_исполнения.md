# Среда выполнения и воспроизводимость

Актуальная среда разработки — Linux на Fedora 44, Docker Engine, Python и Git. Windows/WSL/Docker Desktop упоминаются только как исторический контекст старых проблем и не являются основной инструкцией проекта.

Воспроизводимость обеспечивается фиксированными версиями образов, зависимостей и протоколов, явными seed, отдельными каталогами результатов и SHA-256 для критических файлов. Машиночитаемый статус находится в `docs/status/project-status.yaml`; `docs/research-state.yaml` устарел и помечен как deprecated.

Перед запуском проверяйте дерево и не смешивайте незавершённые изменения с документированием:

```bash
git status --short
```

Команда должна показать только ожидаемые изменения. Для безопасного чтения статуса используйте `git diff --check` после редактирования; предупреждения указывают на пробелы в конце строк или повреждённые разделители.

Сырые данные, PCAP, журналы Zeek, predictions, секреты и каталоги исполнения не являются текстом документации и обычно находятся вне Git. Их контрольные суммы и пути описываются манифестами, которые сами относятся к защищённым артефактам.
