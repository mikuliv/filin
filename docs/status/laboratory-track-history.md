# История лабораторной линии v0.4.x

Эта страница показывает хронологию лабораторной линии. Авторитетная текущая
граница задаётся в `docs/status/v0_4_track.yaml`: последний завершённый этап —
`v0.4.7.3`, следующий допустимый — только `v0.4.7.4`.

| Этап | Добавлено | Результат | Ограничение |
|---|---|---|---|
| `v0.4.0` | реконструкция по подтверждающим материалам и карточка v1 | лабораторный комплект прошёл проверку политики | только синтетические входы |
| `v0.4.1` | временная реконструкция, интервалы, неопределённость и разрывы | вторая редакция закрепила модель времени | порядок не доказывает причинность |
| `v0.4.2` | структурные отношения, граф и конкурирующие гипотезы | принудительный выбор победителя исключён | гипотеза не является фактом |
| `v0.4.3` | локальная консоль и изменяемый слой рассмотрения SQLite | локальные интерфейс и API проверены | не серверная часть и не SIEM |
| `v0.4.3.1` | переработанный операторский интерфейс | проверка в браузере пройдена | возможности не расширены |
| `v0.4.4` | 12 случаев и сохраняемый порядок работы оператора | положительные и отрицательные сценарии, детерминированный экспорт | внешняя применимость не проверена |
| `v0.4.5` | зафиксированные планы запусков, восстановление и проверка сопоставимости | 12 запусков, 8 сравнений, 26 браузерных проверок | сравнение не выбирает и не продвигает кандидата |
| `v0.4.6` | зафиксированное предложение кандидата и обязательные критерии допуска | два побайтно одинаковых обучения, предварительная проверка и ручное решение | предложение не меняет реестр кандидатов |
| `v0.4.7` | слепая проверка с разделением ролей | процедура воспроизводима, предложение получило `failed_validation` | внешнего независимого подтверждения нет |
| `v0.4.7.1` | анализ шести проваленных критериев и корректирующая политика | ошибки пересчитаны по зафиксированным прогнозам, подготовлено семь действий | раскрытый набор нельзя использовать для обучения или приёмки |
| `v0.4.7.2` | новое предложение `proposal:v0472:f02d06231e65df6f` и новый каталог | 48 сессий, 5760 объектов, 24 корректирующих критерия пройдены | разрешена только проверка `v0.4.7.3` |
| `v0.4.7.3` | новый набор из 36 синтетических сессий и две фиксации прогнозов | техническая процедура воспроизводима, но обязательные требования кандидата не пройдены | итог `failed_validation`; регистрация и `v0.4.8` запрещены |

Следующий допустимый лабораторный этап — `v0.4.7.4`: анализ причин отрицательного
результата либо закрытие предложения. Линия не заменяет основной следующий этап
`v0.3.19` и не подтверждает внешнюю применимость.
