# Архитектура staging connector v0.3.16

Три изолированных контейнера образуют цепочку `sensor-runtime → staging-connector → reference-receiver`. Sensor и receiver не состоят в общей сети. Connector — единственный участник обеих внутренних сетей. Порты на host не публикуются.

Соединительный модуль подтверждает приём только после фиксации SQLite/WAL/FULL, доставляет события двумя рабочими процессами пакетами до 50 и фиксирует контрольную точку только после строгого долговечного ACK. Эталонный приёмник — отдельный компонент, не серверная часть: он не импортирует её код, не использует её конфигурацию, базу данных или точки доступа и не выполняет действий промышленной эксплуатации.
