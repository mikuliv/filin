# Основная линия обнаружения и среда выполнения

## Входы

Контролируемые PCAP и журналы Zeek, соответствующие методологии конкретной
кампании. Произвольный промышленная эксплуатация capture не является разрешённым входом.

## Обработка

`collectors/` нормализуют наблюдения, `ml/features/` применяет
контракт сетевых признаков (`network_features_v2`), а реестр кандидатов разрешает только зафиксированный
кандидат `v03154:65a3dd912d845bc1`. Episode policy допускает отказ от определённого
класса. `shadow_event_v2` переносит решение в пассивный среда выполнения contract.

## Доставка

`staging/` и `rehearsal/` подтверждают только изолированный локальный transport.
Эталонный receiver не является промышленная серверная часть. External integration остаётся
запрещённой.

## Текущая граница

Завершён `v0.3.18`; следующий `v0.3.19` ограничен рассмотрение Зафиксировано package и
согласованием trial plan. Полная история находится в
[основной линии](../status/mainline-history.md).
