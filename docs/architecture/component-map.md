# Компонентная карта

| Компонент | Вход | Выход | Контракт | Проверка |
|---|---|---|---|---|
| `collectors/` | наблюдения PCAP и Zeek | нормализованные записи и пассивные события | схемы сборщиков и событий | тесты сборщиков |
| `ml/features/` | нормализованные записи | `network_features_v2` | контракт признаков | тесты признаков |
| `ml/decision/` | оценки зафиксированного кандидата | решение по эпизоду | политика решений и состояний | тесты ML-кампаний |
| `staging/` | контракт пассивного события (`shadow_event_v2`) | подтверждение приёма и трассировка | контракты промежуточного слоя | тесты промежуточного слоя |
| `rehearsal/` | локальный план кампании | подтверждающие материалы доставки | контракты репетиции | средство проверки репетиции |
| `incident_reconstruction/` | пассивное событие и ссылки на подтверждающие материалы | факты, отношения, разрывы, гипотезы и карточка | схемы v0.4 | средство проверки v0.4 |
| `lab_console/` | комплект лабораторной карточки | интерфейс и экспорт ручного рассмотрения | схемы консоли и оператора | средство проверки консоли |
| `external_review/` | зафиксированный пакет | результаты процедуры | рассмотрение внешних контрактов | проверки пакета |
| `backend/` | исторические демонстрационные запросы | демонстрационные ответы | исторические схемы | только исторические тесты |

Подробные README доступны через [каталог компонентов](../reference/component-directory.md).
