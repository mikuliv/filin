# Сквозной поток данных

## Последовательность

1. Контролируемый трафик сохраняется в PCAP.
2. Zeek создаёт журналы сетевых наблюдений.
3. контракт сетевых признаков (`network_features_v2`) формирует 51 причинно допустимый признак.
4. Зафиксировано candidate выдаёт class scores, conformal set и episode decision.
5. контракт пассивного события (`shadow_event_v2`) упаковывает пассивное событие без автоматического действия.
6. Staging connector доставляет событие эталонному локальному receiver.
7. `incident_reconstruction` разрешает ссылки на подтверждающие материалы и строит факты.
8. Детерминированные правила строят temporal/structural relations и разрывы.
9. Несколько гипотез получают evidential profiles без принудительный выбор победителя.
10. Карточка v2 объединяет представления и ограничения.
11. `lab_console` показывает только для чтения source и хранит ручной изменяемый слой отдельно.
12. Экспорт фиксирует решение оператора без изменения Зафиксировано комплект.

## Точки проверки

На каждой границе используются версионированный contracts, schema проверка, identity
anchors и манифест SHA. Наличие связи между объектами означает только проверяемое
отношение, определённое контрактом.

## Запрещённые обратные потоки

Operator notes не возвращаются в модель input, не меняют гипотезы и не входят в
Зафиксировано подтверждающие материалы. среда выполнения output не используется для скрытого дообучения. Результат
лабораторной карточки не разрешает внешнее испытание или промышленная эксплуатация integration.

[хранилища](storage-and-artifacts.md).
