# Сквозной поток данных

## Последовательность

1. Контролируемый трафик сохраняется в PCAP.
2. Zeek создаёт журналы сетевых наблюдений.
3. Контракт сетевых признаков (`network_features_v2`) формирует 51 причинно допустимый признак.
4. Зафиксированный кандидат выдаёт оценки классов, конформное множество и решение по эпизоду.
5. Контракт пассивного события (`shadow_event_v2`) упаковывает событие без автоматического действия.
6. Промежуточный соединительный модуль доставляет событие локальному эталонному приёмнику.
7. `incident_reconstruction` разрешает ссылки на подтверждающие материалы и строит факты.
8. Детерминированные правила строят временные и структурные отношения и разрывы.
9. Несколько гипотез получают профили подтверждений без принудительного выбора победителя.
10. Карточка v2 объединяет представления и ограничения.
11. `lab_console` показывает источник только для чтения и хранит ручной изменяемый слой отдельно.
12. Экспорт фиксирует решение оператора без изменения зафиксированного комплекта.

## Точки проверки

На каждой границе используются версионированные контракты, проверка схемы, идентичность
опорные значения и манифест SHA. Наличие связи между объектами означает только проверяемое
отношение, определённое контрактом.

## Запрещённые обратные потоки

Примечания оператора не используются как входные данные модели, не меняют гипотезы и не входят в
зафиксированные подтверждающие материалы. Результаты среды выполнения не используются для скрытого дообучения. Итог
рассмотрения лабораторной карточки не разрешает внешнее испытание или интеграцию с промышленной средой.

См. [источники истины](../reference/sources-of-truth.md) и
[хранилища](storage-and-artifacts.md).
