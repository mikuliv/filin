# Архитектура лабораторной консоли

## Контуры

- FastAPI обслуживает только `127.0.0.1`;
- token authentication защищает локальную сессию;
- adapters читают Зафиксировано reports и case bundles;
- Jinja templates и статические ресурсы строят operator views;
- SQLite хранит только рассмотрение sessions, progress, notes и decisions;
- экспорт сериализует изменяемый слой и source identity детерминированно.

## Разделение хранения

Source комплект, манифест и семантическая контрольная сумма остаются только для чтения. Изменяемые данные
записываются в `runtime/lab_console/` и не считаются подтверждающие материалы. Удаление среда выполнения
изменяемый слой не меняет исходную карточку.

## Перечень разрешённых значений

Консоль допускает только заранее определённые локальные задачи и известные routes.
Она не запускает команды командной оболочки пользователя, промышленная эксплуатация capture или network actions.

Практический запуск описан в [руководстве](../getting-started/laboratory-console.md),
а файлы компонента — в [README](../../lab_console/README.md).
