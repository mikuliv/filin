# Архитектура лабораторной консоли

Консоль — локальный интерфейс для просмотра и ручного разбора уже созданных
лабораторных артефактов. Она не расширяет полномочия системы и не подменяет
проверку исходных материалов.

## Контуры

- FastAPI обслуживает только `127.0.0.1`;
- token authentication защищает локальную сессию;
- адаптеры читают зафиксированные отчёты и комплекты случаев;
- шаблоны Jinja и статические ресурсы формируют операторские представления;
- SQLite хранит только сеансы рассмотрения, состояние, заметки и решения;
- экспорт детерминированно сериализует изменяемый слой и идентичность источника.

## Разделение хранения

Исходный комплект, манифест и семантическая контрольная сумма остаются только для чтения. Изменяемые данные
записываются в `runtime/lab_console/` и не считаются подтверждающими материалами. Удаление изменяемого слоя
среды выполнения не меняет исходную карточку.

## Перечень разрешённых значений

Консоль допускает только заранее определённые локальные задачи и известные маршруты.
Она не запускает команды оболочки пользователя, промышленный сбор данных или сетевые действия.

Практический запуск описан в [руководстве](../getting-started/laboratory-console.md),
а файлы компонента — в [README](../../lab_console/README.md).
