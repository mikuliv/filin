# Наборы данных

## Назначение

Правила происхождения, описания и controlled references для исследовательских наборов.

## Статус

`current reference`; необработанные чувствительные данные не входят в Git-репозиторий.

## Место в архитектуре

Метаданные наборов поддерживают протоколы экспериментов и генерацию признаков основной линии.

## Основные файлы

Здесь находятся описания источников, разбиений, меток и происхождения; точный состав определяется протоколом соответствующего этапа.

## Разрешённые входы и выходы

Только синтетические или контролируемые входы с документированным происхождением.
Выход — метаданные и локальные артефакты среды выполнения, разрешённые протоколом.

## Границы и запреты

Запрещены персональные данные, секреты, материалы с неизвестными лицензиями и фиксация исходных захватов в Git.

## Безопасный запуск и тестирование

Используйте тесты конкретной ML-кампании; отдельного импортёра для промышленной эксплуатации нет.

## Источники истины

[Происхождение данных](../docs/data-provenance.md) и зафиксированные протоколы соответствующего этапа.
