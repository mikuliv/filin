# Сборщики

## Назначение

Сбор и нормализация наблюдений CSV, Zeek и Suricata, а также пассивная среда
выполнения для событий shadow-контракта.

## Статус

`current`, laboratory-scoped.

## Место в архитектуре

Компонент формирует вход для последовательности построения признаков и событие
`shadow_event_v2` основной линии.

## Основные каталоги

`csv_collector/`, `zeek_collector/`, `suricata_collector/`, `shadow/` и `shadow_trial/`.

## Разрешённые входы

Контролируемые тестовые заготовки и форматы, предусмотренные версионированными
контрактами.

## Выходы

Нормализованные записи, входы построителя признаков и пассивные события с
идентификатором кандидата.

## Границы и запреты

Промышленный захват, скрытая отправка наружу и неизвестный кандидат запрещены.

## Безопасный запуск и тестирование

```powershell
python -m pytest collectors -q
```

## Источники истины

`collectors/shadow/contracts/candidate_registry_v1.json`, collector schemas и
[detection/среда выполнения architecture](../docs/architecture/detection-and-runtime-track.md).
