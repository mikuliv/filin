# Сборщики

## Назначение

Сбор и нормализация наблюдений CSV, Zeek и Suricata, а также пассивная среда
выполнения для событий контракта `shadow_event_v2`.

## Статус

`current`, область применения — лабораторная среда.

## Место в архитектуре

Компонент формирует вход для последовательности построения признаков и событие `shadow_event_v2` основной линии (пассивное наблюдение).

## Основные каталоги

`csv_collector/`, `zeek_collector/`, `suricata_collector/`, `shadow/` и `shadow_trial/`.

## Разрешённые входы

Контролируемые тестовые заготовки и форматы, предусмотренные версионированными
контрактами.

## Выходы

Нормализованные записи, входы построителя признаков и пассивные события с
идентификатором кандидата.

## Границы и запреты

Промышленный захват, скрытая отправка наружу и неизвестный кандидат запрещены.

## Безопасный запуск и тестирование

```powershell
python -m pytest collectors -q
```

## Источники истины

`collectors/shadow/contracts/candidate_registry_v1.json`, схемы сборщиков и
[архитектура обнаружения и среды выполнения](../docs/architecture/detection-and-runtime-track.md).
