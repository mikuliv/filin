# Сборщик CSV

## Назначение и статус

Текущий лабораторный адаптер для версионированных тестовых файлов CSV.

## Место в архитектуре

Преобразует разрешённые столбцы в нормализованные наблюдения перед конвейером вычисления признаков.

## Основные файлы, входы и выходы

Синтаксический анализатор, проверка схемы и тесты находятся в каталоге. Вход — синтетический CSV по
известному контракту; на выходе формируются типизированные записи.

## Границы и запреты

Не допускаются произвольные наборы персональных данных, неявное сопоставление столбцов и неконтролируемая загрузка в эксплуатационную среду.

## Безопасный запуск и тестирование

```powershell
python -m pytest collectors/csv_collector -q
```
