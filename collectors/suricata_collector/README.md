# Сборщик Suricata

## Назначение и статус

Лабораторный адаптер для предусмотренных записей Suricata; он не относится к текущему промышленному пути.

## Место в архитектуре

Поддерживает контролируемое сравнение и тестовые заготовки рядом с основным потоком Zeek.

## Основные файлы, входы и выходы

Синтаксический анализатор принимает версионированные синтетические записи и выдаёт нормализованное представление.

## Границы и запреты

Оповещение Suricata не считается доказательством атаки и не разрешает автоматическую реакцию.

## Безопасный запуск и тестирование

```powershell
python -m pytest collectors/suricata_collector -q
```
