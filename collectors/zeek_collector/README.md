# Сборщик Zeek

## Назначение и статус

Текущий лабораторный сборщик для предусмотренных журналов Zeek.

## Место в архитектуре

Формирует наблюдения, из которых строится `network_features_v2`.

## Основные файлы, входы и выходы

Синтаксический анализатор и код нормализации принимают контролируемые примеры Zeek и возвращают типизированные записи.

## Границы и запреты

Не является промышленным агентом датчика; неизвестные схемы должны отклоняться.

## Безопасный запуск и тестирование

```powershell
python -m pytest collectors/zeek_collector -q
```
