# Статус backend

`backend/` — **ИСТОРИЧЕСКИЙ / ДЕМОНСТРАЦИОННЫЙ ПРОТОТИП**, а не кандидат для
развёртывания. Он не загружает и не обслуживает модель `network_sensor`
версий v0.3.1–v0.3.3. Его уверенность прогноза эвристическая и не является
калиброванной вероятностью ML. Сопоставление MITRE — статический кандидат,
генерация Sigma — черновик, проверка правил не запускается на данных Zeek или
SIEM, а `matched_events` не является результатом настоящего поискового конвейера.

Оценка среды v0.3.3 завершилась с полнотой benign-класса `0.000`; интеграция ML
в этот backend запрещена, пока будущая кампания переработки и независимая оценка
не создадут новую доказательную базу.
