# Политика решения

## Назначение и статус

Текущий зафиксированный слой применения модели, эпизода и состояния для кандидата `v03154`.

## Место в архитектуре

Преобразует оценки модели и выход conformal в решение пассивного эпизода.

## Входы и выходы

Входы закреплены манифестом кандидата; выход формирует класс или состояние отказа
от решения для контракта пассивного события (`shadow_event_v2`).

## Границы и запреты

Принудительный выбор победителя, настройка порога в среде выполнения и автоматическое
применение решения запрещены.

## Безопасный запуск и тестирование

```powershell
python -m pytest ml/tests -q -k decision
```

## Источники истины

Манифест кандидата, артефакты политики состояния и [руководство по неопределённости](../../docs/research/uncertainty-and-abstention.md).
