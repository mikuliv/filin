# Итог v0.4.0

Этап завершён с положительным результатом в отдельной параллельной
исследовательской линии. Созданы строгие контракты, детерминированный
построитель и автономная проверка карточки инцидента из готовых пассивных
событий `shadow_event_v2`.

Официальная синтетическая кампания: 12 из 12 положительных сценариев прошли,
38 из 38 нарушений корректно отклонены. Повторное построение смыслового
результата побайтно идентично. Полный pytest: 1373 passed, 0 failed,
0 skipped, 3 warnings.

Candidate, feature/event contracts и backend не изменены. Fit, calibration,
подбор порогов, внешняя сеть, backend calls и автоматические действия не
выполнялись.

Подтверждена только способность строить и проверять карточку на синтетических
лабораторных материалах. Реальный инцидент, компрометация узла и production
readiness не подтверждаются.

Следующий допустимый этап параллельной линии — v0.4.1. По основной линии
следующим остаётся v0.3.19.
