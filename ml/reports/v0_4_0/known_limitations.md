# Известные ограничения v0.4.0

- использованы только синтетические лабораторные пассивные события;
- реальные данные и данные организации отсутствуют;
- результат модели остаётся наблюдаемым источником, а не доказанным выводом;
- статические правила гипотез покрывают только frozen классы v0.3;
- MITRE ATT&CK mapping является аналитическим соответствием;
- временной порядок не доказывает причинность;
- неполные источники приводят к `insufficient_data`;
- рекомендации предназначены только для ручной проверки;
- автоматическое реагирование, backend и production отсутствуют;
- внешняя оценка модели по линии v0.3 не заменена.
