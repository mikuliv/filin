Текущий версионированный слой признаков; основной контракт — `network_features_v2`.

## Место в архитектуре

Преобразует нормализованные наблюдения во вход зафиксированного кандидата.

## Входы и выходы

Разрешены только поля, доступные на момент принятия решения. Выход содержит стабильный
порядок 51 признака, типы и идентичность предобработки.

## Границы и запреты

Утечка данных после результата, незаметная перестановка и подмена контракта запрещены.

